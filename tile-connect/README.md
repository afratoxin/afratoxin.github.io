# 타일 커넥트

실물 타일과 연결판으로 진행할 수 있는 자체 제작 추론 게임입니다. 기준 타일에서 화살표의 변형을 따라가며, 서로 다른 타일을 모든 빈칸에 한 번씩 배치합니다. 타일 위쪽 표시를 유지하며 답안 타일 자체를 회전하지 않습니다.

- 1단계: 7칸, 회전·좌우 반전·흑백 반전.
- 2단계: 9칸, 중앙 네 칸 반전 추가. 중간·말단 기준에서 거꾸로 추론.
- 3단계: 11칸, 각 화살표에 두 변형을 왼쪽부터 순서대로 적용.
- 90초 도전: 전체 제출만 판정, 오답마다 5초 차감. 기록은 실제 경과 시간에 오답 벌점을 더합니다.
- 자유 연습: 시간 제한과 시간 벌점 없이 연습합니다. 도전 기록에 저장하지 않습니다.

같은 문제 번호와 난이도는 같은 타일·변형·답을 생성합니다. 새 문제는 무작위 번호를 사용합니다. 최고 기록은 이 브라우저에 문제 번호·난이도별로 저장합니다.

## 실물 진행

게임을 시작하고 ‘문제판 · 타일 인쇄’를 누르면 A4 연결판과 잘라 쓰는 타일을 별도 페이지로 인쇄합니다. 인쇄 배율 100%에서 타일 외곽과 배치 칸 크기를 맞췄습니다. 참가자는 표시를 위로 맞춰 타일을 놓고 전체 답을 선언합니다. 진행자는 종료 후 별도로 출력한 정답지로 확인합니다. 참가자용 출력에는 현재 배치와 정답이 들어가지 않습니다. 여러 명이 경쟁할 때 같은 번호·난이도의 세트를 각자 준비합니다.

## 생성과 검증

`engine.js`는 4×4 이진 문양에 가역 변형을 적용해 연결된 트리를 생성합니다. 모든 노드의 문양이 서로 다른 경우만 사용합니다. 기준 타일 하나에서 가역 연결을 양방향으로 따라가면 모든 문양이 유일하게 결정되므로, 타일 배치도 유일합니다. 카드의 문자 표시는 섞인 타일 순서에 붙습니다.

`tests/tile-connect.cjs`는 독립 행렬 변형과 750개 문제의 양방향 복원, 유일 배치, 결정적 재생성, 교환/삭제, 종료·오답 벌점·기록·인쇄 분리를 검증합니다.

```sh
node tests/tile-connect.cjs
node tests/arena-theme.cjs
node tests/hub-groups.cjs
```

공통 디자인은 `../brain-arena/theme.css`를 마지막으로 불러옵니다. 허브의 자체제작 폴더에 등록되어 있습니다.
