# 확통 구조 실험실

평가원 확률과 통계 문항의 구조를 분류하고, 대표 구조의 매개변수를 바꾸면서 문항·답·해설을 함께 살펴보는 첫 초안입니다.

## 실행

GitHub Pages: https://afratoxin.github.io/probability-lab/

빌드와 외부 라이브러리가 없는 HTML/CSS/JavaScript입니다. 웹 서버에서 `index.html`을 열면 됩니다. 외부 API나 모델 호출 없이 브라우저에서 계산합니다.

## 자료와 분류

- 첨부 「수학 평가원 17회분 (2205-2706)_only확통」: 예시문항을 포함한 17회, 23~30번 전 136문항.
- 첨부 「수학 평가원 30회분 (1706-2111)_가나형」: 나형 15회, 전체 450문항에서 확통 117문항 선정.
- 학년도 기준 시험명, 문항 번호, PDF의 1부터 시작하는 페이지와 자체 작성 요약을 `data/catalog.json`에 기록했습니다. 원문 PDF를 공개 저장소에 복제하지 않습니다.
- 한 문항에는 주된 해결 구조 하나를 부여하고, 함수·정수해·조건부확률 등이 겹치는 구조는 보조 태그와 조건에 함께 기록했습니다. 분류는 편집 가능한 초안입니다.
- 구 나형의 자연수 분할, 모비율 추정, 확률밀도함수 등은 당시 교육과정 참고 자료로 구분합니다.

## 계산과 해설

13개 대표 모형은 정수해·배열·선택·함수·이항계수·직접확률·조건부확률·사건 연산·이항분포·이산분포·연속분포·정규분포·추정입니다. 매개변수와 답에 맞추어 해설의 수치, 계산식, 경우 분류가 함께 바뀝니다. 정수와 유리수는 가능한 한 BigInt로 정확하게 계산하며 정규분포의 수치 적분은 근삿값임을 표시합니다.

기출 분류 전체를 제공하지만, 대표 모형은 각 기출의 모든 복합 조건을 그대로 재현하는 변형기가 아닙니다. 상태 전이, 복수 색의 제한 분배, 함수의 복합 관계 등은 기출 지도와 조건 비교에서 살펴보고 다음 구현 대상으로 선택할 수 있습니다. 화면의 기출 조건과 추가 제안이 계산기의 지원 옵션을 뜻하지는 않습니다.

일반 정수에 합만 주는 등 해가 무한한 경우와 조건부확률의 분모가 0인 경우를 별도로 다룹니다. 같은 문자의 일반 원형 배열은 회전 대칭을 고려하는 확장 실험으로 표시합니다.

## 검증

```sh
node --test tests/*.test.mjs
```

알려진 답과 독립적인 작은 표본공간 전수 열거를 비교합니다. 이 저장소의 루트 package.json은 기존 Jekyll 테마의 자바스크립트 빌드용이며 이 실험실은 별도의 빌드가 필요하지 않습니다.

UI 테스트는 외부 의존성 없는 경량 DOM에서 실제 앱과 계산 모듈을 실행합니다. 브라우저의 실제 화면 배치와 렌더링은 이번 환경에서 직접 확인하지 못했습니다.

## 파일 구조

- `index.html`, `style.css`, `app.mjs`: 화면과 상호작용
- `engines.mjs`, `engines/`: 독립 계산 모형
- `data/catalog.json`: 기출 분류·조건·변형 축
- `tests/`: 수학·카탈로그·입력 경계 검증

현재 조건을 링크로 복사하여 공유할 수 있습니다. 서버에 학습기록이나 입력값을 전송하지 않습니다.
