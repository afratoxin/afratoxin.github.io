# 확통 구조 실험실

평가원 확률과 통계 문항의 구조를 분류하고, 대표 구조의 매개변수를 바꾸면서 문항·답·해설을 함께 살펴보는 첫 초안입니다.

## 실행

GitHub Pages: https://afratoxin.github.io/probability-lab/

빌드와 외부 라이브러리가 없는 HTML/CSS/JavaScript입니다. 웹 서버에서 `index.html`을 열면 됩니다. 외부 API나 모델 호출 없이 브라우저에서 계산합니다.

## 자료와 분류

- 첨부 「수학 평가원 17회분 (2205-2706)_only확통」: 예시문항을 포함한 17회, 23~30번 전 136문항.
- 첨부 「수학 평가원 30회분 (1706-2111)_가나형」: 나형 15회, 전체 450문항에서 확통 117문항 선정.
- 학년도 기준 시험명, 문항 번호, PDF의 1부터 시작하는 페이지와 자체 작성 요약을 `data/catalog.json`에 기록했습니다. 원문 PDF를 공개 저장소에 복제하지 않습니다.
- 한 문항에는 주된 해결 구조 하나를 부여하고, 함수·정수해·조건부확률 등이 겹치는 구조는 보조 태그와 조건에 함께 기록했습니다. 분류는 편집 가능한 초안입니다.
- 구 나형의 자연수 분할, 모비율 추정, 확률밀도함수 등은 당시 교육과정 참고 자료로 구분합니다.

## 계산과 해설

13개 대표 모형은 정수해·배열·선택·함수·이항계수·직접확률·조건부확률·사건 연산·이항분포·이산분포·연속분포·정규분포·추정입니다. 매개변수와 답에 맞추어 해설의 수치, 계산식, 경우 분류가 함께 바뀝니다. 정수와 유리수는 가능한 한 BigInt로 정확하게 계산하며 정규분포의 수치 적분은 근삿값임을 표시합니다.

정수해 편집기에서는 a~h 중 일부 변수만 골라 정의역·홀짝·하한·상한을 정하고, 합·차·곱·상수배·제곱과 괄호를 조합한 주식 및 추가 조건을 입력합니다. 일부 변수끼리만 서로 다르거나 크기 순서를 갖는 조건도 만들 수 있습니다. 식은 허용된 문법만 해석하며 자바스크립트 코드를 실행하지 않습니다.

기출 분류 전체를 제공하지만, 대표 모형은 각 기출의 모든 복합 조건을 그대로 재현하는 변형기가 아닙니다. 상태 전이, 복수 색의 제한 분배, 함수의 복합 관계 등은 기출 지도와 조건 비교에서 살펴볼 수 있습니다. 화면의 기출 조건과 추가 제안이 계산기의 지원 옵션을 뜻하지는 않습니다.

일반 정수에 합만 주는 등 해가 무한한 경우와 조건부확률의 분모가 0인 경우를 별도로 다룹니다. 같은 문자의 일반 원형 배열은 회전 대칭을 고려하는 확장 실험으로 표시합니다.

학생용 해설은 하한 치환·중복조합·상한의 포함배제·여사건·대칭·약수쌍·같은 것이 있는 순열 등을 조건에 맞게 사용합니다. 복합식은 핵심 변수의 가능한 경우를 먼저 줄이고 나머지 변수의 경우의 수를 묶어 계산합니다. 내부 검산 방식과 학생에게 제시하는 풀이를 구분합니다. 유한 범위가 확인되지 않거나 계산 범위를 넘는 임의의 식은 임의 상한을 붙여 답을 만들지 않고 조건 수정을 안내합니다.

정규분포표는 첨부 확통 PDF의 2022학년도 9월 모의평가 27번(PDF 11쪽)의 네 행을 재구성했습니다. 표 밖의 현재 문항용 근삿값은 별도로 표시합니다. 신뢰구간은 기출표의 반올림 임계값을 기본으로 하고 정밀 계산도 선택할 수 있습니다.

## 문항의 수치 범위

화면에 제공하는 모든 모형은 공통 제한을 통과합니다. 입력 수와 문자의 값은 절댓값 999 이하이며, 경우의 수의 답과 풀이에 사용하는 표본공간의 크기, 정확한 확률의 분자·분모도 999 이하로 제한합니다. 제한을 넘는 값을 999로 잘라 정답을 바꾸지 않습니다. 조건 자체를 허용 범위로 제한하거나 수정 안내를 표시합니다.

조정 범위는 현재 조건에 따라 바뀝니다. 정규분포의 구간은 실제로 묻는 확률변수의 평균에서 표준편차의 세 배 이내입니다. 표본평균이면 표준편차 σ/√n을 기준으로 하며, 슬라이더는 −3~3의 표준화 값과 실제 구간 끝값을 함께 연결합니다. 정규분포표의 확률은 기존처럼 소수 근삿값으로 제시합니다.

계산 모듈 자체는 독립적인 수학 검산을 위해 더 넓은 범위를 지원하지만, 앱에 노출되는 13개 모형은 `exam-limits.mjs`의 동일한 검증을 거칩니다. 관련 기출의 원래 수치와 출처의 학년도는 문항 생성 제한의 대상이 아닙니다.

## 검증

```sh
node --test tests/*.test.mjs
```

알려진 답과 독립적인 작은 표본공간 전수 열거를 비교합니다. 이 저장소의 루트 package.json은 기존 Jekyll 테마의 자바스크립트 빌드용이며 이 실험실은 별도의 빌드가 필요하지 않습니다.

UI 테스트는 외부 의존성 없는 경량 DOM에서 실제 앱과 계산 모듈을 실행합니다. 브라우저의 실제 화면 배치와 렌더링은 이번 환경에서 직접 확인하지 못했습니다.

## 파일 구조

- `index.html`, `style.css`, `app.mjs`: 화면과 상호작용
- `engines.mjs`, `engines/`: 독립 계산 모형
- `structured-editor.mjs`: 일부 변수 조건과 복합식 편집
- `data/normal-table.mjs`: 출처가 확인된 기출 정규분포표
- `data/catalog.json`: 기출 분류·조건·변형 축
- `tests/`: 수학·카탈로그·입력 경계 검증

현재 조건을 링크로 복사하여 공유할 수 있습니다. 서버에 학습기록이나 입력값을 전송하지 않습니다.

조건은 슬라이더를 드래그하여 조절합니다. 숫자뿐 아니라 선택형 조건과 적용 여부도 눈금에 맞춰 이동할 수 있고, 직접 입력·선택도 함께 지원합니다. 드래그 중에도 문항·정답·해설을 갱신합니다.

## 화면 구성

넓은 화면에서는 왼쪽 조정 탭, 가운데 문제, 오른쪽 해설을 화면 높이에 맞추어 함께 표시합니다. 조정 항목은 기본·식·변수·조건·예제로 나누고 긴 항목은 페이지로 전환합니다. 변수별 편집도 선택한 변수의 카드만 표시합니다. 전체 페이지를 길게 스크롤하지 않으며 긴 해설과 자료는 해당 영역 안에서 읽습니다.

좁은 화면에서는 조정·문제·해설 패널을 탭으로 전환합니다. 패널을 바꾸어도 입력한 조건과 계산 결과는 유지됩니다.
