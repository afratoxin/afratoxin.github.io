# 색 공 선택과 상자 분배 확장

기존 확통 실험실을 확장한다. 사용자는 기출 조건의 목록보다 기출에 나올 법한 조건들을 조합하는 생성기를 요청했다. 색은 1~6종, 색별 수량은 독립적이며 일부 색과 상자만 선택하여 조건을 적용한다.

Approaches: 기존 빨강/파랑 슬라이더에 조건별 스위치를 계속 추가하면 조건 조합과 스크롤이 커진다. 임의 코드 실행은 검증과 해설을 어렵게 한다. 기존 안전한 식 문법과 형식화된 조건 규칙을 함께 사용하는 방향으로 구현한다. 이 선택은 기존 사용자의 부분 변수·복합식·드래그·3단 UI 요구에 따른 구현 판단이다.

선택 모형은 기존 selection ID와 두 색 공유 링크를 호환한다. 복원/비복원, 순서, 최초/마지막 색과 순서 관계, 색별 개수와 색 가짓수, AND/OR/여사건, 조건부확률을 제공한다. 식 a~f는 뽑힌 색별 개수이다.

새 distribution 모형은 색별 공을 모든 상자에 분배한다. 같은 색 공의 구별과 상자 구별을 각각 선택한다. 일부 상자의 총량/선택한 색 수량/색 가짓수, 빈 상자/단색/혼합/모든 색 상자 수, 식 조건을 지원한다. 식 a~e는 각 상자에서 선택한 색의 합이다. 구별하지 않는 상자는 전체 상자에 동일한 조건만 적용하며 위치에 의존하는 식과 부분 상자 조건은 거절한다.

분포 결과에 조합·다항계수 가중치를 적용하여 계산한다. 확률에서 색 구성들을 등확률로 간주하지 않는다. 상자 구별 제거는 중복된 비어 있지 않은 열의 팩토리얼을 반영한다. 풀이에는 조합/중복조합/여사건/조건부확률을 우선 사용하고 경우표는 구성별로 묶는다.

입력, 문자값, 답, 분자·분모와 표본공간은 절댓값 999 이하이다. 과도한 구성은 답을 자르지 않고 거절한다. 슬라이더 허용값을 현재 조건으로 갱신하며 직접 입력과 공유 링크도 같은 검증을 거친다. 공 0개, 상자 1개, 불가능한 사건과 분모 0을 검사한다.

기존 3단 viewport와 페이지 전환을 유지한다. 색 편집은 변수 탭, 규칙 편집은 조건/식 탭에 한 항목씩 표시한다. 본 변경은 정적 JS와 BigInt만 사용하며 추가 의존성이 없다. 범위의 한계는 문서에 명시하며 모든 가능한 수학적 조건을 지원한다고 주장하지 않는다.
