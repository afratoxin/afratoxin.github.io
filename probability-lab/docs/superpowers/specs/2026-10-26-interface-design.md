# 확통 실험실 인터페이스 개편

기능이 추가되면서 작은 글자·반복된 경계선·같은 강도의 버튼이 겹쳐 조정과 읽기가 어려워졌다. 기존 왼쪽 조정/가운데 문제/오른쪽 해설의 viewport 구성, 드래그, 세부 조건, 공유 링크와 999 제한을 유지하며 모든 탭의 디자인과 탐색을 개선한다.

디자인 판단: 기존 파란 관리도구 스타일을 부분 수정하는 대신 아이보리 배경, 흰 문제 지면, 짙은 초록 강조색의 학습 작업대 방향을 사용한다. Linear와 Desmos의 공식 페이지를 참고 대상으로 확인했으며 이미지 원본은 다운로드하지 않았다. 서비스 UI를 복제하지 않고 얇은 탐색 영역·명확한 선택 상태·작업과 결과의 공간적 분리 원칙만 적용한다. 이미지 장식 대신 실제 조작 요소와 수식에 시각적 우선순위를 준다.

범위: 상단 탐색, 5개 조정 탭, 공과 변수 편집기, 문항/정규분포표/관련 기출, 정답/풀이/경우표/분포, 기출 지도와 조건 비교를 동일한 색·타이포·버튼·간격 체계로 정돈한다. 숫자 미세 조절 버튼과 필터 초기화는 기존 검증 경로를 통한다. 선택한 탭에 맞는 짧은 안내와 색 구분도 제공한다.

표현: 본문 14px 이상, 문제 17~19px, 선택/비선택 및 포커스가 색 외 테두리·형태로도 구분된다. 긴 문장과 수식은 줄바꿈하고 필요한 경우 패널 내부에서 읽는다. 좁은 화면은 기존 패널 탭 방식과 키보드 탐색을 유지하며 reduced motion을 존중한다. 외부 폰트는 선택적으로 로드하고 시스템 폰트로 바로 읽을 수 있게 한다.

검증: 새 미세 조절 버튼의 실제 허용값 이동, 직접 입력·드래그 동기화, 필터 초기화, 탭별 안내, 색 대상 구분을 DOM에서 검사한다. 기존 전체 수학/레이아웃/UI 검사를 수행하고 새 CSS까지 cascade 계약에 포함한다. 이 환경에는 브라우저 QA 도구가 없으므로 실제 픽셀 배치는 확인했다고 주장하지 않는다. GitHub 최신 master의 다른 프로젝트 변경을 보존하고 Pages 배포 완료를 확인한다.
