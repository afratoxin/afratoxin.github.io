# Balance, pattern and relay practice

These games use independently generated problems and the shared BRAIN ARENA interface. No video frames or third-party artwork are bundled.

## Source and rule checks

- **Balance scale:** [tvN D ENT / Diggle's Cooperative Hold'em clip](https://www.dailymotion.com/video/x7lhap7) identifies the original match. The [episode's rule record](https://www.namu.moe/w/더%20지니어스:그랜드%20파이널/10화) describes using a specified number of counters to balance two sides; each numbered position gives the contribution of one counter there. The browser practice permits stacking counters and accepts every allocation meeting the stated number and equality. Distances are decorative and are not multiplied into the numbered contributions.
- **Same Pattern:** [season 1 final rule record](https://www.namu.moe/w/대학전쟁/5회전), original name `숨은 패턴 찾기`: a 10-column, 8-row arrow board; a 2×2 target; rotations permitted, reflections excluded; answer by upper-left coordinate; correct +1, incorrect/duplicate −1; a valid end declaration +3, an early end −2. Six targets use two boards, replaced before round four. Rotation changes both arrow directions and positions.
- **Time Shift and Pixel Art:** [season 3 relay rule record](https://www.namu.moe/w/대학전쟁3/3회전). The original games use number consumption and mental rotation of three of nine 3×3 colored pictures. The user's practice requirements are authoritative for this version: Time Shift supplies exactly the digits 1–6 or 1–7, once each; Pixel Art accepts three card numbers and internally checks all quarter-turn rotations, with no rotation controls. Every accepted overlay forbids repeated instances of the same primary color in one cell, including same-color-only overlap. Distinct primaries mix as orange, purple, green or black. Reflections are excluded.
- **Block Count:** [season 1 relay rule record](https://www.namu.moe/w/대학전쟁/4회전) identifies counting all cubes in the depicted stack. The practice now stores each occupied unit cube explicitly. Nine families include separate pillars, elongated stepped solids, towers, pyramids, bent stairs, open wells, arches, bridges and courtyards. Holes are real empty cells, not decorative dark faces. Four views help expose openings. All solid components connect to the ground, and all empty cells communicate with the exterior; sealed invisible cavities are excluded.

## Browser practice choices

These games are solo practice. Free practice has no deadline. Challenge mode uses a clearly labeled two-minute limit per problem or pattern round; this is a browser practice setting, not a claim about the broadcast's timing or team rules. Incorrect submissions have a ten-second retry delay. Scale progresses through five levels. Time Shift, Pixel Art and Block Count each progress through eight levels; their introductory difficulty remains gentle while the upper limit increases. Clear advances, forfeit reveals a valid answer and retains the difficulty for the next fresh problem. Pattern uses six rounds and end-declaration scoring; the original alternating-team turns are omitted.

Time Shift's generated statement families use a 24-hour clock: six digits and a single easy forward move, minute carry, backward borrowing, then seven digits, midnight crossings and two or three successive moves. Adjacent digit slots form a two-digit hour or minute; displayed move amounts are fixed clues. These are new practice sentences, not transcriptions of broadcast questions. All valid arrangements are accepted, including alternatives to the generation witness. Pixel Art validates every possible rotation of the chosen three cards instead of requiring a fixed witness. Stages 1–5 retain their target coverage requirements, while stages 6–8 require denser mixed targets and add similar distractors. Block Count keeps an introductory ceiling of 27 cubes and increases structure size and complexity across eight levels. A shuffled family history avoids repeating the same form before other available forms appear. Review layers count actual occupied cubes, including roofs with air below them.

## Verification

`tests/arena-puzzles.cjs` checks generated balance solutions, exact 1–6/1–7 consumption and clock rollovers, independently computed pixel rotations and rejection of every same-color overlap, occupied-cube layers and SVG cube counts, and independent geometric matching of arrow rotations. Controller checks cover five/eight-stage completion, same-level retries, deadline and cooldown boundaries, card return, duplicate pattern answers, early end penalties and the six-round board replacement.

`tests/arena-theme.cjs` checks the hub and every catalog game for the shared final stylesheet and consistent folder navigation. Existing Genius tests additionally check that random A–P labels remain fixed throughout a board's memorization, hidden-answer and review phases, and that solution coordinates use the same labels.

## Mystery Sign

[The Genius: Grand Final episode 12 rule record](https://www.namu.moe/w/더%20지니어스:그랜드%20파이널/12화) identifies the final's second game: infer a hidden binary rule from input/output hints, over eleven rounds. This is a solo adaptation with six generated examples up front, eleven correct answers, optional untimed/two-minute practice, and ten-second retry. The broadcast's alternating hint requests, opponent, items and scoring are omitted.

`mystery.js` contains 49 distinct rules in six families: arithmetic, digits/visual counts, number properties, comparisons/intervals, Korean number names and decimal representation. Prime numbers and decimal notation are separate families. Korean uses standard Sino-Korean names with omitted initial 일 before 십/백/천. Decimal-length clues only use finite decimal answers; terminating decimals have no recurring period. Generated examples are compared against all registered rules; every remaining rule must give the same answer for the unseen target. This guarantees consistency within the registered rule set, not logical uniqueness among all imaginable functions. All new rules and examples are independent practice content.

`tests/arena-blocks.cjs` checks nine shapes, supports, open-air cavities, real overhead gaps, layer totals and four-view bounds. `tests/mystery-sign.cjs` checks independent known answers, all 49 rule generators, Korean/prime/decimal edge cases, balanced family coverage and target agreement among consistent rules.
