# 감염과 면역 · 2차 학습 허브

2026.11.23–24의 제공 강의 9개와 「감염과 면역 족보 - 2차」를 대조하여 새로 구성한 5지선다 예상문제 225개입니다. 기존 1차 콘텐츠를 같은 경로에서 교체했습니다.

| --- | --- | ---: |
| 면역약리학 | 이창한 | 25 |
| 통풍관절염 | 신기철 | 25 |

`bank.json`만 활성 문제은행입니다. 문항별 정답은 0-based이며, 개별 선지 해설은 원래 선지 순서와 대응합니다. 세션에서 선지 순서를 섞어도 채점과 해설은 원래 인덱스를 기준으로 연결합니다. 강의별 정답 위치는 각각 5회씩 배분했습니다.

문항은 족보 변형/강조점 응용으로 구분합니다. `examRefs`는 실제 확인한 족보의 PDF 쪽수·연도·번호와 유형의 참고이며 과거 문항 원문이라는 의미가 아닙니다. `sourcePages`는 강의 PDF 첫 장부터 센 실제 1-based 쪽수입니다. 인용된 강의·족보 페이지 278개를 WebP로 제공합니다. 원본 PDF 전체와 로컬 절대 경로는 배포하지 않습니다.

올해 면역약리학의 수업 진행 안내에 따라 후반 자료 문항은 보충 범위 태그를 붙였습니다. 현재 강의와 상충하는 복원 답안은 그대로 복제하지 않았고, 상세 안내는 허브에서 확인할 수 있습니다. 3개 묶음 작성 후 다른 작성자가 교차 검토하여 답의 유일성, 오답 개연성, 선지 길이와 해설을 수정했습니다.

## 학습 동작

- 강의별 이어풀기: 미풀이 다음 최신 오답 순서. 전체·선택 범위·고난도 학습을 지원합니다.
- 실전 시험: 범위에서 최대20문항을 섞어 출제하며 답을 수정할 수 있습니다. 제출 전 정답·해설을 표시하지 않습니다. 미응답은 시험 점수에서 정답으로 계산하지 않지만 기존 학습 기록을 오답으로 덮어쓰지 않습니다.
- 오답·별표: 최신 채점 결과와 별도로 관리합니다. 풀이·별표·세션은 현재 브라우저에 저장됩니다. 기기 간 자동 동기화는 없으며 JSON 기록 내보내기/가져오기를 지원합니다.
- 이전 범위 저장값은 삭제하지 않으며 새 범위와 합산하지 않습니다. 저장이 제한되면 현재 방문의 메모리로 학습합니다. 여러 탭의 문항 기록은 최신 시각으로 합치고 별표 변경은 이전 상태와 대조하여 반영합니다.
- 숫자1–5로 선택하고 Enter로 채점/다음 문항으로 진행합니다. 모바일에서는 문제 아래에 해설을 제공합니다.

## 검증

설치나 빌드 없이 정적 HTTP 서버에서 실행합니다.

```text
node --test infection-immunity-hub/core.test.mjs
node infection-immunity-hub/validate.mjs
node --check infection-immunity-hub/app.mjs
```

데이터 검증은 강의당 최소20문항, 고유ID/발문, 5개 고유선지·개별해설, 정답범위, 근거쪽수와 이미지 파일 존재를 검사합니다. 핵심 동작 테스트는 선지섞기 채점, 최신 오답 교체, 실전시험 제출, 미응답 점수처리, 세션저장, 저장실패, 두 탭 기록병합과 별표해제 보존을 확인합니다. 브라우저에서도 실제 풀이·시험·새로고침 복원·근거 이미지·모바일/데스크톱 화면을 검증했습니다.
