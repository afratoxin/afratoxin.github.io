`bank.json`만 활성 문제은행입니다. 문항별 정답은 0-based이며, 개별 선지 해설은 원래 선지 순서와 대응합니다. 세션에서 선지 순서를 섞어도 채점과 해설은 원래 인덱스를 기준으로 연결합니다. 문항을 다시 풀 때 선지 순서를 새로 섞습니다.

문항은 족보 변형/강조점 응용으로 구분합니다. `examRefs`는 실제 확인한 족보의 PDF 쪽수·연도·번호와 유형의 참고이며 과거 문항 원문이라는 의미가 아닙니다. `sourcePages`는 강의 PDF 첫 장부터 센 실제 1-based 쪽수입니다. 현재 인용하는 강의·족보 페이지 566개를 WebP로 제공합니다. 원본 PDF 전체와 로컬 절대 경로는 배포하지 않습니다.

올해 면역약리학의 수업 진행 안내에 따라 후반 자료 문항은 보충 범위 태그를 붙였습니다. 현재 강의와 상충하는 복원 답안은 그대로 복제하지 않았고, 상세 안내는 허브에서 확인할 수 있습니다. 3개 묶음 작성 후 다른 작성자가 교차 검토하여 답의 유일성, 오답 개연성, 선지 길이와 해설을 수정했습니다.

## 강의록 단독 풀이 기준 · 2026.11.25 재검토

정답 판별의 내용 근거를 제공된 강의 슬라이드·수업 주석으로 한정했습니다. 족보는 출제 형식·표현·난도만 참고하며, 강의 파일 말미에 재수록된 과거 문항만으로 근거를 대신하지 않습니다. 외부 임상지침·세부기전·약제·검사성능·수치를 알아야 풀 수 있는 문항과 오답 해설은 제외·교체하거나 실제 강의의 명시 내용으로 한정했습니다.

기존225개를 원저자와 다른 검토자가 실제 PDF·도표·주석과 전수대조했습니다. 당시의 225문항(강의별25개)에 `lectureBasis.summary/pages`로 정답을 결정하는 내용과 실제쪽수를 기록하고 채점후 화면에 표시합니다. 기존225개 각각의 판단·쪽수별 확인내용은 `source-review.json`에 남깁니다. 자동검사는 기록 누락과 범위·연결 오류를 검출하며, 강의내용 자체의 충분성 판단은 PDF대조로 수행했습니다.

질문·선지·정답이 바뀐 52개는 새ID를 사용합니다. 교체문항은 이전문항의 풀이 완료·정오답을 승계하지 않습니다. 교체문항이 포함된 기존세션은 무효화하여20문항시험이 일부만 남아 채점되는 일을 방지하며, 바뀌지 않은 문항의 학습기록은 유지합니다.

## 11월25일 알레르기·천식·암면역 추가

6강 145문항을 추가하여 당시 총 370문항으로 확장했습니다. 기존225문항의 ID·문제·정답·해설은 그대로 보존했습니다. 신규문항도 문항별 `lectureBasis` 및 `source-review.json`의 `additions`에 결정적 강의 근거와 실제페이지를 기록했습니다.

성인·소아의 진단역치와 치료단계는 각 강의의 명시 기준을 구분합니다. 본문에 명시되지 않은 옛 족보의 규칙이나 수치·기전은 외부지식으로 보충하지 않습니다. CBL7은 PDF2–8쪽의 본문·수업주석만 내용근거로 사용하며,9–15쪽 재수록 기출은 제외합니다.

다른 제공 강의의 명시근거가 필요한 문항은 `extraSources`에 문서ID와쪽수를 분리해 기록할 수 있습니다. 화면과 근거창 모두 소속강의와 지원강의를 구분하며, 주된 판별근거는 `lectureBasis.extraSources`에 기록합니다. 11월25일 추가 당시의 교차인용문항 수는 0개입니다.

## 학습 동작

- 강의별 이어풀기: 미풀이 다음 최신 오답 순서. 전체·선택 범위·고난도 학습을 지원합니다.
- 실전 시험: 범위에서 최대20문항을 섞어 출제하며 답을 수정할 수 있습니다. 제출 전 정답·해설을 표시하지 않습니다. 미응답은 시험 점수에서 정답으로 계산하지 않지만 기존 학습 기록을 오답으로 덮어쓰지 않습니다.
- 오답·별표: 최신 채점 결과와 별도로 관리합니다. 풀이·별표·세션은 현재 브라우저에 저장됩니다. 기기 간 자동 동기화는 없으며 JSON 기록 내보내기/가져오기를 지원합니다.
- 이전 범위 저장값은 삭제하지 않으며 새 범위와 합산하지 않습니다. 저장이 제한되면 현재 방문의 메모리로 학습합니다. 여러 탭의 문항 기록은 최신 시각으로 합치고 별표 변경은 이전 상태와 대조하여 반영합니다.
- 숫자1–5로 선택하고 Enter로 채점/다음 문항으로 진행합니다. 모바일에서는 문제 아래에 해설을 제공합니다.
