- 문항마다 다섯 보기의 설명과 실제 강의 쪽별 캡처를 제공합니다. 필요할 때 CDC 등 일차자료를 보충 근거로 연결합니다. 예상문제와 기출 원문을 구분하며 개인 Anki 원문·이미지·노트 ID는 게시하지 않습니다.
- 새 문항은 활성 진입점 `quiz-bank.mjs`에 합칩니다. 역사 검토용 `study-bank.mjs`와 별도 표 암기 범위를 되살리지 않습니다. 기존1461문항과 풀이·별표 저장 키를 유지합니다.

## 표 암기 퀴즈 통합

- 기존 표 암기 540문항 전부의 학습 내용을 일반 퀴즈와 대조했습니다. 같은 사실을 다시 묻는 521문항은 활성 범위에서 제외하고 고유한 19문항을 해당 강의의 일반 문제로 옮겼습니다.
- 단어가 다른 정도, 질문 방향을 바꾼 정도, 이미 일반 문제의 정답 설명으로 학습하는 사실도 대조합니다. 같은 정답 단어가 있다는 이유만으로 중복으로 분류하지 않습니다. 각 판단과 대응 문항은 `recall-consolidation.mjs`에 기록합니다.
- 19문항의 보기·정답·강의 근거와 ID를 유지하며 발문은 독립적으로 이해할 수 있게 다듬었습니다. 기존 일반 1442문항의 내용과 ID는 유지합니다.
- 허브, 별표, 오답과 전체 합계에 별도의 표 암기 그룹을 두지 않습니다. 예전 `#drill` 주소는 강의별 문제로 이동합니다. 항생제·병리 정리표 등 참고 자료는 유지합니다.
- **활성 진입점은 `quiz-bank.mjs`**입니다. `study-bank.mjs`와 옛 표 관련 파일은 과거 출처 검토·기록 연결을 위한 입력 자료이며 독립적인 퀴즈로 실행하지 않습니다.

### 기존 기록

- 옮긴 19문항과 보기·정답·발문이 동일한 중복 270문항은 기록을 대응 ID로 연결하며 더 최신의 정오답을 우선합니다. 표현·범위가 달라진 중복 문항은 별표만 연결하고 실제로 풀지 않은 일반 문제를 완료로 표시하지 않습니다.
- 기존 일반 퀴즈의 진도·별표·세션 저장 키를 유지합니다. 표 암기의 원본 진도·별표·세션은 삭제하지 않습니다.
- `recall-migration.mjs`는 성공한 저장 대상별로 이관 상태를 남깁니다. 실패한 저장만 다시 시도하며, 이관 뒤 사용자가 별표를 해제하면 예전 별표로 되돌리지 않습니다. 이관 판단은 실제 브라우저 저장값을 읽어 일시적인 메모리 저장을 영구 저장으로 오인하지 않습니다.
- 휴대폰·컴퓨터 간 서버 동기화는 포함하지 않습니다. 기록은 현재 브라우저에 저장하며 저장이 제한되면 이번 방문의 메모리로 동작합니다.

## 문항과 근거

- 제공된 강의 PDF, 사용자 HWP/PDF 정리본과 족보, 관련 Anki의 대응 관계·기전·위험군 중심 학습 경향을 대조한 예상문제입니다. 짧은 임상 단서와 비슷한 균명·검사명·기전·치료 키워드를 사용합니다.
- `examRefs`는 확인한 족보의 연도·번호 및 유형 참고입니다. 예상문제가 과거 문항 원문이라는 뜻은 아닙니다. 원문 문제는 CBL 기출 범위에 별도로 표시합니다.
- `sourceRefs`는 1부터 시작하는 실제 PDF 쪽수입니다. 인용된 강의 963개 페이지를 WebP로 제공하며 채점 후 해설 옆에서 확대합니다. 원본 PDF, HWP·Anki 원본 및 개인 학습 자료는 포함하지 않습니다.
- 틀린 설명 찾기는 옳은 설명 4개와 틀린 설명 1개이며, 정정문·보기별 판단·강의 근거를 제공합니다. 대상을 바꾸거나 작용 방향·위치·검사 의미·관련 질환을 바꾸는 형태로 출제합니다.
- 강의의 보충 메모를 임상 지침 전체로 일반화하지 않습니다. 예를 들어 면역저하자의 국소 대상포진은 파종 배제 전까지 공기·접촉주의가 필요하며, B19 노출만으로 임신 의료진의 일괄 근무 배제를 정답으로 만들지 않습니다.
- 병리에서는 원충·기생충·절지동물 문항을 제외합니다. Pneumocystis는 진균으로 유지합니다. PathEdu 조직 사진은 진단 소견과 가까운 감별을 해설합니다.
- 11월 18일 의료관련감염·방어기전손상환자·레오/코로나/노로 강의의 내용도 포함합니다. CD4·이식 시간표는 위험을 정리하는 교육 기준이며 면역억제 강도·예방요법 등에 따른 실제 차이는 해설에 표시합니다.

## 학습 동작

- 상단 기본 메뉴는 학습 허브 / 별표 문항 / 오답 노트입니다. 강의별 문제는 일반 / 세균·진균 / 바이러스 / CBL로 나눕니다.
- 선택 범위 전체에서 미풀이 → 오답 순서로 이어갑니다. 복귀 시 최신 문항별 기록으로 남은 문항을 재구성하며 문항 수로 세트를 끊지 않습니다.
- 숫자 1–5, 숫자패드 1–5, OX의 1/2와 채점 후 Enter를 지원합니다. 문제와 해설·근거를 PC에서 나란히 제공합니다.
- 별표·오답의 개별 문항 다시 풀기와 강의별 진행도는 같은 일반 퀴즈 기록을 사용합니다.

## 실행과 검증

설치나 빌드 없이 저장소 루트에서 정적 HTTP 서버로 실행합니다.

```text
node --test infection-immunity-hub/*.test.mjs
node infection-immunity-hub/validate.mjs
```

모든 모듈 import와 HTML의 캐시 버전은 `20261119e`입니다. 자동 검증은 문항·출처·근거 이미지, 틀린 설명 구조, 범위와 큐 복원, 키보드, 별표·오답, 540개 이관 판단의 전수 대응, 19개 고유 문항 보존과 기록 이관을 확인합니다. 기록 검증에는 최신 결과 우선, 의미만 같은 문항의 완료 방지, 재실행, 별표 해제, 부분 저장 실패와 재시도를 포함합니다.
