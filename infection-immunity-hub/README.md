## 문항과 근거

- 제공된 강의 PDF, 사용자 HWP 정리본과 족보, 관련 Anki의 대응 관계·기전·위험군 중심 학습 경향을 대조하여 작성한 예상문제입니다. 짧은 임상 단서와 비슷한 균명·검사명·기전·치료 키워드를 사용합니다.
- `examRefs`는 실제 확인한 족보의 연도·번호 및 유형 참고를 뜻합니다. 새 예상문제가 과거 문항 그대로라는 뜻은 아니며, 족보의 불확실한 CBL/일반 분류를 단정하지 않습니다.
- `sourceRefs`는 1부터 시작하는 실제 PDF 쪽수입니다. 인용된 강의 816개 페이지를 WebP로 제공하며 채점 후 해설 옆에서 확대할 수 있습니다. 원본 PDF, 족보 원문 전체, HWP·Anki 원본 및 개인 학습 자료는 포함하지 않습니다.
- 강의의 보충 메모를 임상 지침 전체로 일반화하지 않습니다. 예를 들어 면역저하자의 국소 대상포진은 파종 배제 전까지 공기·접촉주의가 필요하며, B19 노출만으로 임신 의료진의 일괄 근무 배제를 정답으로 만들지 않습니다. 관련 추가 근거는 해당 문항에 표시합니다.
- 병리 범위에서는 원충·기생충·절지동물 문항을 제외합니다. Pneumocystis는 진균으로 유지합니다. PathEdu의 진단 가능한 조직 소견은 사진 단서·핵심 연결·가장 가까운 감별로 해설합니다.

## 학습 동작

- 상단 기본 메뉴는 학습 허브 / 별표 문항 / 오답 노트입니다. CBL은 강의 선택 및 표 암기의 네 번째 대분류입니다.
- 선택한 범위 전체에서 미풀이 → 오답 순서로 이어갑니다. 새로고침·복귀 시 최신 문항별 기록으로 남은 문항을 재구성하며, 문항 수로 세트를 끊지 않습니다.
- 공통 키보드 처리로 숫자 1–5, 숫자패드 1–5, OX의 1/2, 채점 후 Enter를 지원합니다. 입력창과 실제 모달의 조작을 보호하며, 숨겨진 이전 세트 확인 상태가 숫자 입력을 차단하지 않습니다.
- 기존 `infection-immunity.*.v1` 저장 키를 유지합니다. 유지 문항과 원문 기출의 ID는 보존하고, 내용이 바뀐 79개 예상문항에는 새 ID를 부여합니다. 제외 문항의 저장 기록은 지우지 않습니다. 문항별 정오답·현재 범위·별표는 현재 브라우저에 저장합니다. 저장이 제한되면 이번 방문의 메모리로 동작합니다.

## CBL 기출 원문 — 2026-11-16

- 허브의 별도 `CBL 기출 원문`에서 CBL1 18 / CBL2 6 / CBL3 3 / CBL4 18 / CBL5 11 = 총 56문항을 제공합니다. CBL2의 6개 중 1개는 강의록에 재수록된 2021년 TBL2 6번이며, 실제 시험 분류를 보존합니다.
- 원본 족보의 CBL1–5 구역 55문항과 위 TBL 연계 1문항을 문항별로 캡처했습니다. 페이지·단을 넘는 문항은 여러 캡처로 구성하고 그림과 표를 보존했습니다. 78개 문항 캡처, 그림 선지 5개, CBL6 출제 없음 기록 2개를 제공합니다.
- 모든 문항 캡처에 Windows OCR을 실제 실행한 원시 결과와 원본 대조 교정문을 구분하여 저장합니다. 원문 선지 280개를 그대로 유지하고 각 선지에 상세 해설을 작성했습니다. 원문 순서가 답안 번호와 일치하며, 생성형 문제의 선지 치환 규칙으로 기출을 바꾸지 않습니다.
- `정답·해설 보기`는 기록을 바꾸지 않고 근거를 열어 줍니다. 숫자키·숫자패드로 답을 선택하면 정상 채점하며 Enter로 이동합니다. 기출도 별도 저장 키 `infection-immunity.cblpast.*.v1`로 진도·오답·별표를 보존하고 전체 별표·오답 노트에 통합합니다.
- 2025년 CBL4 64번은 족보의 전원정답 처리를 유지합니다. 임상적으로 모든 보기가 타당하다는 뜻과 구분하여 해설합니다. 혈청은 SFTS 유전자검사에 사용할 수 있는 검체이며, 전원정답 처리 이유는 원문에 설명되어 있지 않습니다.
- 2019년 CBL4 3·4·74번은 정답표에만 있고 원문이 없어 사용자 지시에 따라 문항 목록에서 제외했습니다. CBL6은 족보가 2019–2023년 미출제로 기록한 캡처를 보여 주며, 표기가 없는 2025년 미출제를 단정하지 않습니다. 2023년 CBL1 99번은 지문에 언급된 그람염색 사진이 원본에도 누락되어 있어 그 사실을 표시합니다.
- CBL4·5 전용 강의 PDF는 제공되지 않았습니다. 문항의 기전·감별을 설명하는 관련 강의의 실제 페이지를 연결하고 그 범위를 표시했으며, 일부 치료·검사 판단은 IDSA·CDC·질병관리청 등 1차 근거로 보완했습니다. 원문 정답과 현재 임상 해석이 일치하지 않거나 단서가 부족한 경우 별도로 설명합니다.
