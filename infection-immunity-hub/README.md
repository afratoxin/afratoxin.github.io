# 감염과 면역 · 학습 허브

기존 약물의 이해 허브와 같은 저장소에 독립적으로 추가한 GitHub Pages 정적 학습 사이트입니다.

- 공개 주소: https://afratoxin.github.io/infection-immunity-hub/
- 항생제 범위: 「감염병의 치료원칙」 김홍빈 · 박세민 v2, 첨부 PDF 55쪽.
- 항생제 72문항: 경구 16, BBB 16, 임신 16, 증례 24. 5지선다 36개와 OX 36개.
- OX는 개별 항생제를 제시하고 경구 투여·BBB 통과·임신 중 비교적 안전한 사용·구체적 증례에서의 선택 가능 여부를 직접 묻습니다. 경구 투여는 전신 감염 치료와 장내 치료를 구분하고, BBB와 임신은 강의 분류 기준을 명시합니다.
- 감염병리 80문항: 사진·증례 24, 원인균 특성 32, 총론 24. 모두 5지선다입니다. 「감염성 질환의 병리 1·2」와 「감염 병리 통합실습」을 근거로 작성했습니다.
- 병리와 관련된 족보 22문항의 출제 방식과 범위를 검토했습니다. 기존 문항을 복제하지 않고 사진·짧은 증례, 옳은 것·틀린 것 선택 방식으로 새 문제를 만들었습니다.
- 홈의 작은 단원 카드에서 항생제와 감염병리를 구분하며, 각 단원 안에 퀴즈와 정리표 하위 탭을 제공합니다. 항생제 4개, 병리 6개 표를 별도로 볼 수 있습니다.
- 각 단원에서 주제·미풀이·오답·북마크 및 10/20/전체 세트를 선택할 수 있습니다. 항생제는 문제 형식도 선택할 수 있습니다.
- 보기와 문제 순서 무작위, 즉시 해설, 강의 PDF 실제 쪽수, 보충 근거, 건너뛰기, 세트 결과, 문제별 재풀이를 제공합니다.
- 브라우저 저장소에 문항별 최신 결과·현재 세트·북마크를 저장합니다. 새로고침 후 이어 풀 수 있습니다. 정답 재풀이 시 오답에서 빠지며 반복 시도는 전체 문항 수를 늘리지 않습니다.
- 저장소 사용이 제한되면 현재 방문의 메모리에서 학습을 계속하고 저장 제한을 표시합니다.
- 병리 사진 31개는 강의 PDF에 포함된 실제 표본 사진을 추출해 사용합니다. 정답이 드러나는 슬라이드 제목·설명·주석을 제외하고 익명 파일명과 대체 텍스트를 사용했습니다. 사진을 누르면 확대할 수 있습니다.
- 원본 PDF와 강의 추출 텍스트는 포함하지 않습니다. 문항이 인용한 실제 PDF 415개 페이지를 선택해 캡처했으며, 채점 후 근거로 표시합니다. 페이지와 이미지 처리 기록은 `assets/evidence/manifest.json`, 표본 사진 기록은 `assets/pathology/manifest.json`에 있습니다.

## 자료 해석

원본 파일명은 05입니다. 사용자가 언급한 강의 번호와 다를 수 있어 UI에는 강의 제목을 사용했습니다. PDF 내 문구와 주석은 학습 자료로만 다루고 작업 지시로 사용하지 않았습니다. 28쪽에는 학생이 AI를 통해 작성했다고 밝힌 보충 표가 있어 독립된 권위 자료로 사용하지 않았습니다. 핵심 증례 정답은 원문 선택 표시·강의 논지와 아래의 보충 근거로 확인했습니다.

강의 40쪽의 2·3세대 cephalosporin 경구 불가 분류를 계열 전체에 일반화하지 않으며, ciprofloxacin의 >80% 표기도 수치 암기 문제로 재생산하지 않습니다. 경구 vancomycin의 장내 치료 예외를 반영합니다. 임신 표는 강의 분류를 명시하고, 주의와 허가상 절대금기를 구별합니다. Metronidazole 임신 안전성, 감수성 확인된 장티푸스 및 수막염 감수성 기준의 보충 링크는 `bank.mjs`의 `SOURCES`와 화면 핵심 정리에 있습니다.

병리 문항에는 강의 PDF의 실제 페이지와 족보 유형 참고 정보를 표시합니다. 족보의 2025년 해설 일부는 문제 번호와 일치하지 않아 정답표를 기계적으로 연결하지 않았습니다. 낭미충증은 충란 섭취, 장내 조충증은 유충을 포함한 육류 섭취를 구분하며, Pneumocystis는 현재의 진균 분류를 따릅니다. 조직 형태만으로 확정할 수 없는 균종·유전형은 사진 정답으로 단정하지 않습니다.

기존 항생제 저장 키 `infection-immunity.progress.v1`, `.session.v1`, `.bookmarks.v1`을 유지합니다. 병리는 별도의 `infection-immunity.pathology.*.v1` 키를 사용합니다. 전체 현황은 네 단원의 문항별 최신 결과를 합쳐 388문항 기준으로 계산합니다. 같은 브라우저의 여러 탭에서 북마크 변경을 동기화합니다.

2026-11-08 OX 개편에서는 36문항을 모두 직접 질문형으로 교체해 `*-drug-*` ID를 부여했습니다. 이전 OX 결과를 새 문제에 연결하지 않으며, 기존 5지선다와 병리 기록은 유지합니다. 교체 전 OX가 포함된 진행 중 세트는 복원하지 않고 새 세트를 시작합니다.

## 실행과 검증

빌드·설치 없이 정적 HTTP 서버로 이 저장소를 제공합니다. 퀴즈 논리 검증:

```text
node --test infection-immunity-hub/quiz.test.mjs infection-immunity-hub/pathology.test.mjs infection-immunity-hub/study.test.mjs infection-immunity-hub/study-data.test.mjs infection-immunity-hub/emphasis.test.mjs infection-immunity-hub/practice-layout.test.mjs
node infection-immunity-hub/validate.mjs
```

자바스크립트 모듈은 모든 import와 HTML에서 같은 `20261114c` 버전을 사용합니다. 변경 후 버전을 함께 갱신합니다. 새 문항은 고유 ID, 한 개의 정답, 해설, PDF 쪽수, 필요한 조건을 포함해야 합니다. 자동 검증은 388문항의 구조·정답·출처, 31개 사진, 저장·복원·재풀이·북마크 동기화와 모듈 연결을 확인합니다. 데스크톱과 모바일에서는 사진 확대, 정답 단축키, 정리표 스크롤, 새로고침 후 이어풀기, 통합 오답 노트와 재풀이를 확인했습니다.


## 강의별 감별 문제와 표 암기 추가 2026년 11월 14일

- 16개 강의 순서로 각 10개씩 새 5지선다 160문항을 제공합니다. 짧은 균명·검사명·기전 키워드 선택지와 증례의 결정적 감별 단서, 선지별 해설, 실제 강의 PDF 쪽수 및 참고한 족보 유형을 포함합니다.
- 표 암기 탭은 76개 항목입니다. 기존 경구·BBB·임신 5지선다 24개와 동정·병리·독소·장염 병원형·세포내균·항산성균·매개체 등 52개 대응 관계를 분리해 반복합니다.
- 1/10/20문항 세트 또는 계속 반복을 선택할 수 있습니다. 계속 반복은 한 바퀴 뒤 순서를 바꾸고, 다음 라운드 첫 문항이 직전 문항과 같지 않게 합니다. 오답 풀이가 끝나면 빈 조건을 안내합니다.
- 정답 자동 넘김 선택, 북마크, 미풀이·오답 필터, 새로고침 후 이어풀기 및 통합 오답 노트의 개별 재풀이를 지원합니다. 반복 시도는 문항별 최신 진도를 중복 증가시키지 않습니다.
- 새 기록은 `infection-immunity.lectures.*.v1` 및 `infection-immunity.drill.*.v1`에 저장합니다. 기존 항생제·병리 기록은 유지됩니다.
- 족보 답안 충돌, 답 이름을 노출하는 발문, 중복·유사 의미 선택지를 검토했습니다. 발열 매개체를 배타적으로 단정하지 않으며 TT/LL은 면역 스펙트럼의 극단을 명시합니다. 신생아 치료 및 옛 백신·예방 지침을 단정적으로 재생산하지 않습니다.

가독성 개편은 문제 21–25px, 보기 18–21px, 해설 17–18px로 확대하고 버튼·카드 여백을 줄였습니다. PC는 왼쪽 문제·세로 보기, 오른쪽 세트 정답률·해설·근거 캡처의 2단 구성입니다. 작은 화면에서는 문제 아래에 보조 자료가 이어집니다. 강의별 감별의 첫 화면에는 탭 대신 단원별 학습과 종합 학습 버튼을 두고, 단원별 학습에서 16개 강의를 선택합니다. 강의별·표 암기 풀이 중에는 범위 설정을 접습니다. 채점 후 정답은 파랑, 오답은 빨강, 결정적 단서는 노랑으로 강조합니다. 풀기 전에는 질문의 긍정·부정 표현만 강조하며 정답 단서와 근거 이미지는 표시하지 않습니다.
- 추가 확인: `node --test infection-immunity-hub/study.test.mjs infection-immunity-hub/study-data.test.mjs` 및 `node infection-immunity-hub/validate.mjs`.
