## Explicit browser adaptations

Archery and Death Note remain solo games. Death Note retains twelve digit cards, free choice of card count, one point for a completed expression, and three total for code success. The optional factorial, square and power references remain. Forfeit now displays a sample expression and code.

Territory offers computer opposition or solo 50-point practice. The computer uses only actual expressions verified with the same 1–6 twice-per-digit limit as the player; it passes when its expression database cannot provide a move. Two consecutive passes end the game on current scores. This is a bounded practice opponent, not an optimal solver. The broadcast layout is the default; new boards vary digits and prepare solvable opening lines while preserving the blocked layout.

Ace Four offers ten-problem standalone drills plus a twelve-problem, three-cycle circuit. Following the user's timing request, successive correct problems reduce 120→110→…→10 seconds. The circuit ends after twelve successes, so no zero-second problem is created. A wrong answer, expiry or forfeit ends the circuit and reveals the current answer. Standalone retries retain the previous cooldown behavior. Zero Sum uses the shrinking limit as observation time; its separate ten-second response window is a solo adaptation because the precise broadcast response duration was not established. Free practice removes deadlines.

Either Or uses ten distinct three-digit addends: there is no shared addend across the two sums. The sums stay close while their complete horizontal arrangements differ. Pixel Number 2 now mixes sparse red figures, already complete red figures, overlapping red pieces, and blue pixels that do not affect red. The red union is never a full 15-pixel rectangle; subtraction still produces the exact standard digit for each background group.
