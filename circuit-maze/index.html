CIRCUIT LABYRINTH

회로 미로

이 문을 열면, 저 문이 닫힌다.
회로를 전환하고 코어를 회수하세요. 빠른 판단이 높은 점수가 됩니다.

도전 준비지도는 항상 공개

길을 읽고,
회로를 설계하세요.

시작과 동시에 지도 공개 + 시간 측정
코어를 모두 모아 출구로 이동하세요.

● 나◆ 코어↗ 출구□ A/B/C 스위치

흰 선 = 벽 · 색 실선 = 닫힌 문 · 색 점선 = 열린 문
문의 A0 / A1 표시는 통과할 수 있는 A 회로 상태입니다.

경과 시간00:00.0
현재 점수10,000
코어0 / 3

난이도를 고른 뒤 시작하세요. 지도를 읽는 시간도 기록에 포함됩니다.

이동 횟수는 감점되지 않습니다. 점수는 클리어 시간으로만 결정됩니다.

현재 회로 상태

방향키 / WASD
스위치 칸에서
Space / Enter

스위치를 밟기만 하면 바뀌지 않습니다. 버튼으로 전환 여부를 선택하세요.

최고 기록은 난이도별로 이 기기에 저장합니다. 같은 미로 연습은 별도로 표시합니다.

규칙과 점수
  1. 지도는 계속 보입니다. 관찰 제한 시간이 없습니다.
  2. 스위치 A를 누르면 A가 0 ↔ 1로 바뀝니다. A0 문과 A1 문이 서로 반대로 열립니다.
  3. 모든 ◆ 코어를 모은 뒤 ↗ 출구에 도착하세요. 회수 순서는 자유입니다.
  4. 시간이 짧을수록 높은 점수. 에너지나 이동 제한은 없습니다.

탭을 바꾸어도 시간은 흐릅니다. 재도전은 새 타이머로 시작하는 연습이며, 첫 도전 최고 기록에 합산하지 않습니다.
