규칙과 방송 참고 자료
  1. 평면도 2장, 각 3문제씩 총 6문제입니다. 평면도와 3D 시점은 계속 표시됩니다.
  2. 물음표는 3D 화면을 보는 사람의 발밑 한 칸입니다. 시선을 향한 방향도 추론해야 합니다. 화면을 회전하거나 미로 안을 이동할 수 없습니다.
  3. 지도에서 통로를 누르거나 좌표를 입력한 뒤 제출하세요. 정답 +1점, 오답은 감점 없이 10초간 제출 제한입니다.
  4. 정답을 맞히거나 포기하면 지도에 실제 위치와 보는 방향을 표시합니다. 포기는 0점이며 정답을 즉시 공개합니다.
