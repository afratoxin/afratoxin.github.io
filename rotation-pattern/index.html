게임 방법 · 난이도
  1. 기억하기. 불빛이 켜진 칸을 기억하세요. 도전은 5×5판, 불빛 5개, 암기 10초로 시작합니다.
  2. 방향 따라가기. 불빛이 완전히 꺼지면 판이 90°·180° 회전하거나 상하·좌우로 뒤집힙니다. 왼쪽·오른쪽 뒤집기는 모두 좌우 반전이고, 위·아래 뒤집기는 모두 상하 반전입니다. 여러 변형은 현재 보이는 판을 기준으로 차례대로 적용됩니다.
  3. 패턴 복원하기. 움직임이 끝난 판에서 불빛의 최종 위치를 모두 선택하고 ‘선택 완료’를 누르세요. 다시 누르면 선택이 취소됩니다. 필요한 개수를 모두 골랐을 때 Enter 키로도 제출할 수 있습니다.
  4. 다음 단계. 정답이면 불빛이 하나 늘어납니다. 5×5에서 6문제를 연속으로 맞히면 6×6(7단계), 다시 6문제를 연속으로 맞히면 7×7(13단계)로 넓어집니다. 변형은 1회에서 시작해 4·10·17단계에 각각 2·3·4회가 됩니다. 판이 커질 때는 변형 횟수를 유지하고 암기를 10초로 늘려 적응할 시간을 줍니다. 같은 크기의 판 안에서는 암기를 10초에서 9초로, 마지막 두 단계는 8초로 줄입니다. 정답 제한시간은 5×5 30초, 6×6 35초, 7×7 40초입니다. 오답 또는 시간 초과 시 도전이 끝나며 정답과 내 선택을 함께 확인할 수 있습니다. 총 20단계입니다.

기록은 통과 단계 수가 우선이며, 같으면 정답을 고른 총시간이 짧을수록 높습니다. 암기·애니메이션 시간은 이 기록에서 제외합니다. 자유 연습과 같은 패턴 복습은 도전 기록에 포함하지 않습니다.

소리를 켜면 불빛과 정답에 맞춰 짧은 효과음이 재생됩니다. 다른 창으로 전환하면 화면을 가리고 일시 정지합니다. 움직임 줄이기를 사용하는 환경에서는 3D 뒤집기 대신 짧은 전환을 보여줍니다.
