# 회전 패턴

불빛 위치를 기억한 다음, 90°·180° 회전과 상하·좌우 뒤집기가 끝난 판에서 최종 위치를 선택하는 공간 기억 게임.

- 도전: 20단계. 5×5, 불빛 5개, 암기 10초로 시작해 정답마다 불빛 한 개 증가. 6연속 정답 후 7단계에서 6×6, 다시 6연속 정답 후 13단계에서 7×7로 확장. 변형은 4·10·17단계에서 2·3·4회로 증가. 확장 시 변형 수 유지·암기 10초 복원·정답 시간 30→35→40초로 늘려 급격한 난도 상승을 피함. 암기는 같은 크기 내에서 10→9초, 마지막 두 단계는 8초.
- 자유 연습: 5~7칸 정사각형, 불빛 5~20개, 암기 5/7/10초, 변형 1~4회, 정답 제한시간 선택.
- 모든 변형은 화면 좌표계에 왼쪽부터 순차 적용. 좌우 뒤집기는 Y축 180° 회전, 상하 뒤집기는 X축 180° 회전. 변형 뒤에 좌표를 정규화하여 화면상의 답과 판정 좌표가 일치한다.
- Web Animations API로 판 전체를 움직이고, CSS로 불빛 페이드와 정답 파동을 표현. 움직임 줄이기 환경에서는 짧은 전환을 사용.
- 정답 선택 중에만 정답 타이머가 흐른다. 도전 순위는 통과 단계 수 우선, 동률이면 성공한 답의 선택 시간 합계. 자유 연습·같은 패턴 복습은 기록 제외.
- 화면을 떠나면 타이머·판 애니메이션이 정지하고 판을 가림. 계속하기로 재개.
- 순수 엔진은 `engine.js`, 화면 흐름은 `game.js`. `node tests/rotation-pattern.cjs` 및 공통 테마·허브 검사 실행.

실물로는 양면 격자판, 자석 표식, 가림막, 타이머로 동일하게 진행할 수 있다. 진행자가 패턴을 보여준 뒤 가리고 판을 돌린 다음, 참가자가 최종 위치에 표식을 배치한다.

새 난이도의 기록은 `rotation-pattern-record-v2-small`에 저장한다. 이전 난이도 기록은 삭제하지 않고 별도 보존한다.
