### 1. 정수의 출력
---
정수를 출력할 때에는 %d 서식지정자를 사용합니다. 
~~~c
#include <stdio.h>

int main(void) {
  int a, b;
      printf("a b : ");
      scanf("%d%d", &a, &b); // ← 3 4를 입력한다. (띄어쓰기임 쉼표 아님), 문자 개수만큼 %d 넣기. (쉼표로 하고 싶으면 %d,%d)
      printf("a = %d\n", a);  
      printf("b = %d\n", b);
  return 0;
~~~

[출력결과]
a 입력: 3 4 \n
a = 3 \n
b = 4
