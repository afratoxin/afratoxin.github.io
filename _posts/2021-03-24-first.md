### 1. 정수의 출력
---
정수를 출력할 때에는 %d 서식지정자를 사용합니다. 
~~~C
#include <stdio.h>

int main(void) {
  int a; //변수 선언 (a는 정수다!)

  printf("a : "); //
  scanf("%d", &a);  //변수 입력을 받는다! 그걸 %d로 읽어서 &a 에다가 갖다놓아라

  printf("a = %d\n", a);  // a는 %d이고, 줄바꿈 후 a 출력
  return 0;
~~~
