# 약물의 이해 · 족보 단원별 회독

2026 「약물의 이해」 족보의 학생 복원 문제를 강의별로 표시합니다.

- PDF 문제 부분 4–88쪽과 답안표 89–101쪽을 대조해 실제 문항 **579개**를 식별했습니다.
- **453개**는 그림 없이 다섯 선지와 답안으로 채점 가능한 퀴즈입니다. **126개**는 그림 필요, 선지 누락, 복수 해석, 텍스트 추출 오류 등의 이유로 `원문 확인 목록`에 보존했습니다.
- 원문 PDF 페이지와 스캔 이미지는 공개하지 않습니다. 그림 문항은 표기된 강의·연도·번호·쪽을 소지한 PDF에서 확인하세요. 채점형 문항의 보기 순서는 연습 때마다 섞이지만 정답은 원문 답안표의 위치에 맞추어 함께 변환합니다.
- 과거 강의 번호는 족보대로 유지하고, 변경된 2026 강의 번호는 단원 카드에 병기합니다. **2026년 29강 내용이 변경**되었으므로 과거 29강 문항의 비중을 그대로 적용하지 마세요.
- 원본은 학생들이 기억을 토대로 재구성한 자료로, 답안표에도 불명확함·복수 정답·복원 오류가 명시되어 있습니다. 이 페이지의 정답은 확정된 의학 지식이 아닌 원문 답안표의 표기입니다.
