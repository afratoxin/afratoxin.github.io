# 2027 LEET Pilot Implementation Plan

> **For agentic workers:** Use the supplied user specification and bounded parallel tasks. User review is after the 40-question pilot.

**Goal:** 2027학년도 40문항의 원문·태그·선지별 해설을 열람하고 검수할 수 있는 GitHub Pages 페이지.

**Architecture:** buildless HTML/JS, 독립 JSON 데이터, 원본 문항 WebP. 외부 서비스 의존 없이 GitHub Pages 하위 경로에서 실행한다.

**Tech Stack:** Python/PyMuPDF/Poppler, HTML/CSS/JavaScript.

**Spec:** 2026-10-25-design.md

## Global Constraints
- 범위 2701~2740, 다른 연도 확장 전 사용자 검수.
- 지문 왼쪽, 해설 오른쪽, 태그 위쪽, hover 설명과 클릭 목록.
- 원문 충돌/추출 한계는 유지하고 공개적으로 검수 상태 표시.

## Review Focus
- 두 열 문항이 섞이지 않아야 함.
- 표·그림·수식은 원본 이미지에 남아야 함.
- 출처 표시 정답과 독립 풀이의 차이는 숨기지 않아야 함.
- 필터 교집합/검색/고유 주소가 일관되어야 함.
- 한글/특수기호와 작은 화면의 가독성이 유지되어야 함.
