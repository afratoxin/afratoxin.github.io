# 전체 아카이브 범위와 분류

2009학년도 예비시험과 2009~2027학년도 본시험, 총 20회 755문항을 포함합니다. 2010~2018은 회차당 35문항, 나머지는 40문항입니다. 모든 문항에 분야·중간 소재·문항 유형·풀이 논리와 각 분류의 부여 이유를 작성했습니다.

분야는 23개, 소재는 중간 범주 125개입니다. 구체적인 사건·인물·실험명은 제목과 분류 근거에 두고, 소재를 지나치게 세분하지 않습니다. 기존 분류 링크 130개는 현재 분야 또는 중간 소재로 연결합니다.

현재 공개 데이터는 `explanations-only`입니다. 자체 작성 해설·풀이 과정·보기 판단·5선지별 해설을 모두 제공하며, 새로 추가한 715문항의 원문·이미지·PDF는 포함하지 않습니다. 이들 문항은 소장 통합 PDF의 회차·문항번호·쪽수로 찾을 수 있습니다. 2027 수정본 40문항은 원문과 해설을 그대로 유지합니다.

2020~2023의 125문항, 625개 선지 해설은 실제 보기의 법리·논증·수치·반례를 명시하도록 보완했습니다. 1034·2305·2435는 2026-10-26 사용자 확인 후 원문을 재풀이하여 각각 ②·②·①로 해설을 수정했습니다. 경매의 출발 가격 설정 취지, 반복 위반의 2차·3차 기준과 가산 합산, 혈액형별 인원 증감과 양수 반례를 반영하고 기존 불일치 표시를 해제했습니다. 수정 근거와 해설 원본은 `data/analyses/review-1034-2305-2435.json`에 보존합니다.

자체 해설은 검수용 초안입니다. 데이터 완전성과 화면 동작 검증, 일부 문항의 독립 풀이를 수행했으나 전체 문항을 외부 공식 정답표와 대조한 상태는 아닙니다.
