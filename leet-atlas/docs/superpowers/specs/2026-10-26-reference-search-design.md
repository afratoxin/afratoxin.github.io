# 출제 구상으로 참고 문항 찾기

## 목적과 사용자 선택

사용자는 문항 내용을 기억해서 찾는 것뿐 아니라, 만들고 싶은 새 문항의 소재·인물 관계·논증 구조를 자연어로 설명하고 기존 755문항에서 참고 대상을 찾고 싶다. 예: “인문 논리학 소재의, 2명이 서로 싸우는 문항”. 사용자는 별도 계정과 호출 비용 없이 사이트 안에서 검색하는 방식을 선택했다.

현재 검색은 공백으로 나눈 모든 문자열이 제목·원문·분류·태그 근거에 포함되어야 한다. 의미 유사도, 인물 수, 대화 구조, 관련성 순위는 사용하지 않는다. 위 예시는 현재 0건이다.

## 접근 방식과 제안

1. 단어 사전과 표현 변형만 확장: 빠르고 가볍지만 사전에 없는 바꿔 말하기에는 약하다.
2. 브라우저 의미 검색에 분류·구조 정보를 결합: 첫 검색 자료 준비가 필요하지만 새로운 문장 표현을 비교할 수 있다. 이 방식을 제안한다.
3. 외부 AI 호출: 자유로운 해석에는 유리할 수 있으나 계정·호출 비용·서버 관리가 필요해 사용자의 선택에서 제외한다.

## 동작

- 기본 “참고 문항 추천”은 입력 문장을 기준으로 관련성이 높은 문항부터 보여준다. 기존 “키워드 검색”도 선택할 수 있다. 문항번호는 정확한 ID가 우선한다.
- 기존 분야·태그·연도·북마크·검수 필터는 사용자가 고른 조건을 계속 엄격하게 적용한다. 자연어에서 추정한 분야·인물 수·대립 관계는 순위에 반영하고, 확인되지 않은 조건까지 만족했다고 단정하지 않는다.
- “싸우는”은 인문·논리학 같은 문맥에서 의견 대립·반박·논박·반례를 찾도록 해석한다. 실제 폭행·몸싸움을 원하는 문맥과 구별한다. 등장인물 이름뿐 아니라 소크라테스/라케스, 어머니/자녀, 판매자/구매자 등도 고려한다. 단순히 갑/을이 나온다는 이유로 두 사람의 논쟁으로 분류하지 않는다.
- 결과에는 맞는 분류·구조와 실제 원문/해설에서 가져온 짧은 근거를 표시한다. 완벽히 맞지 않는 후보를 완전 일치라고 표시하지 않는다. 새 문항이나 해설을 생성하는 기능은 이번 범위에서 제외한다.
- 검색창에 예시 문장을 제시한다. 입력 즉시 가벼운 표현·분류 검색 결과를 제공하고, 의미 비교가 준비되면 순위를 갱신한다. 준비 중/준비 실패 상태를 구별하고 오래된 요청이 최신 검색 결과를 덮어쓰지 않도록 한다.

## 구성과 유지보수

- GitHub Pages의 정적 사이트를 유지한다. 모델은 브라우저 작업자에서 실행하고 입력 문장을 외부 AI 서버로 보내지 않는다. 별도 API 키·로그인·유료 서비스는 사용하지 않는다.
- 한국어를 지원하는 multilingual-e5-small의 ONNX 양자화 모델과 Transformers.js를 검증된 버전으로 고정한다. 최초 검색 때 공개 배포처에서 모델과 실행 자료를 내려받고 브라우저 캐시를 재사용한다. 모델 파일만 약118MB이므로 첫 준비에는 데이터 사용과 대기 시간이 있음을 안내한다.
- 755문항의 제목·분류·해설·원문을 미리 계산한 검색 자료를 사이트에 포함한다. 긴 원문은 나누어 계산해 뒷부분 정보가 빠지지 않게 한다. 문항별 검색 설명에는 사실로 확인한 구조와 근거만 사용한다.
- 모델 로딩 실패/메모리 제한/캐시 차단 시에도 검색창과 기존 필터는 작동하며, 가벼운 관련 표현 검색으로 전환했음을 표시한다. 모델 파일을 GitHub 저장소에 복제하지 않는다.
- 원문·이미지·정답·해설·태그 ID·검수 기록은 수정하지 않는다. 개인 교정본은 기존대로 표시·검색할 수 있고, 공개 원문에서 계산한 의미 자료라는 한계는 숨기지 않는다.
- 정확한 검색 점수 조합, 문서 분할 길이, 캐시 형식, 모바일 최적화는 구현 시 실측으로 정한다. 모델 결과를 수동 목록으로 치환해 예시만 통과시키지 않는다.

## 확인 기준

- 사용자 예시의 상위10개 안에 1321·1512·1717·2218·2318 중 최소3개가 들어간다. 이들은 철학적 논박이나 두 사람의 실제 의견 대립이 있는 문항이다.
- “엄마랑 자식이 공부 안 하는 것도 원인이 되는지 논쟁”에서2218, “홈즈 콧구멍 가지고 소설에서 참인 게 뭔지 싸우는 문제”에서2318을 상위5개에서 찾는다.
- 두 명의 논쟁과 세 명 이상의 참거짓 퍼즐, 의견을 병렬로 제시한2523을 구별한다.2523을 단순히 두 이론을 찾는 검색에서 배제하지 않는다.
- 실제 몸싸움, 연도 제한, 정확한 문항 ID, 관련 없는 입력, 빠른 연속 입력, 로딩 실패를 확인한다. 근거 표시와 기존 필터/북마크/개인 교정본도 회귀 검사한다.
- 기존 전체 검사와 실제 배포 화면의 입력·순위·근거·원문 이동을 검증한다.
