# 연도별 출제 경향·난이도 분석

사용자 요청: 예비시험부터 2027학년도까지 각 회차의 핵심 논리, 발문, 선지, 소재를 분석하는 탭과 문항별 난이도 그래프를 추가한다. 필요한 외부 정답률·총평을 찾아 비교한다.

## 구성

- 주요 메뉴에 `연도별 분석`을 추가하고 최신 회차를 기본으로 연도를 선택한다.
- 회차별 자체 총평, 논리·발문·선지·소재의 정량 분포와 구체적인 대표 문항 링크를 제공한다.
- 문항별 그래프는 원문에서 계산한 상대적 풀이 부담 추정과 외부 공개 정답률을 분리한다. 미확보 정답률은 빈 값이며 추정값으로 채우지 않는다.
- 외부 통계는 제공 기관, 표본 성격, 책형·문항 대응 확인 여부, 출처 링크를 표시한다. 임의 참여 표본을 전체 응시자 통계로 설명하지 않는다.
- 비교 기준 회차를 선택할 수 있고, 문항 수가 다른 회차는 비율로 비교한다. 복수 태그의 합은 100%일 필요가 없다.
- 그래프의 각 문항은 원문·해설로 연결하며, 표 형태의 대체 자료도 제공한다.

## 구현 판단

공식 정답률만 사용하는 방안은 과거 연도의 자료 공백이 크므로 단독으로 쓰지 않는다. 자체 추정만 사용하는 방안은 외부 검증 자료를 놓친다. 두 자료를 출처·단위별로 분리하는 혼합 구성을 선택한다. 이는 구현자의 판단이며 사용자가 구체적인 산식이나 디자인을 지정한 것은 아니다.

풀이 부담은 읽기량, 조건·예외 표현, 논리 종류, 보기 비교량의 상대적 위치를 결합한 5단계 지표로 제공한다. 실제 정답률이나 검증된 심리측정 난이도를 뜻하지 않는다. 모든 산식·특징·누락값 처리 기준을 화면에서 확인할 수 있게 한다.

## 보존 조건

기존 문항·정답·해설·분류·검색·북마크·최신순 기본값을 유지한다. 다른 작업에서 진행 중인 선지 해설 표시 변경도 덮어쓰지 않는다. 새로운 외부 서비스나 계정 연결 없이 정적 사이트에서 작동한다.
