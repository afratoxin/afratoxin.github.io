# 문항 제작 작업실 검증 기록

## 요구와 확인 자료

- 자연어 제작 의도→추천: 실제 브라우저 E5로 지원금의 비율 감액·고정액 가산·독립 선택지형 요청을 검색했다. 1908 보상금 산정이 첫 후보였고 선택한1022와 함께 설계 자료로 연결했다. 전체755문항의 기존 일반 검색 경로를 사용한다.
- 참고 기출의 출제 논리: 요약·풀이 단계·분석 프로필·오답 함정을 표시하고 원문 상세로 연결한다. 두 기출을 선택한 프롬프트는13,027자였고 두 ID, 원문 및 전체 선택지 해설을 확인했다. 자료를 자르지 않는다.
- 완전한 새 문항: ChatGPT 웹에 실제 생성·재검토 프롬프트를 입력했다. 첫 응답은 후행 쉼표 및 정답 중복 문제가 있었고, 첫 보완 응답도 해설에서만 수정하여 choices와 불일치했다. 풀이 결과를 먼저 확정하고 실제 choices를 수정하도록 일반 지침을 강화한 다음 최종 JSON을 받았다. 형식과 모든 선택지 계산을 별도로 대조했다.
- 최종 시험 문항은 ‘지원금 산정에서 비율 감액과 정액 가산의 적용 순서’이며 지문·발문·5독립 진술·정답⑤·전체 풀이·5선택지 해설·5축 분류·5기준 검토가 있다. 실제 금액(만 원)은 갑8200, 을7700, 병9500, 정7700, 무10000. 정의 역순 적용은7600으로 차이100이다. ①~④ 참,⑤의10500만 원만 거짓이다. 이 사례의 계산 검산은 모든 가능한 생성 결과의 정답을 보장하지 않는다.
- 가져오기·분류·검토: 브라우저에서 완성 JSON을 가져와 지문/선택지/분류/AI 자체 검토가 동시에 표시됨을 확인했다. 형식 검사와 AI 자체 검토·사용자 확인은 별도다. 실제 잘못된 첫 응답을 가져오면 거부하면서 기존 초안을 유지한다.
- 보존·반복 제작: 사용자 확인1/5와 참고ID1022·1908을 포함한 JSON 파일을 실제로 내려받고, ‘새 작업’으로 백업·초기화한 뒤 파일 선택으로 복원했다. 제목·참고2개·확인1/5가 복원됐다. 브라우저 새로고침도 저장된 의도·메모·참고 기출을 복원했다.
- 반응형:375px 실측 폭에서 문서 scrollWidth=clientWidth=375, 가로 넘침 없음. 버튼·입력·파일 복원과 단계가 한 열로 표시된다.
- 회귀: 전체 Node272/272, 공개 원문755·선택지 해설3775·이미지715+40 보존 검증 및 기존 데이터 검증 통과. 소스 자료는 변경하지 않았다.
- 공개 배포:90fe34441f1bdbbd37b7047de7f9c707da566fb6, Pages 실행41194263776의 build/deploy/report 작업이 모두 성공했다. 배포된 트리42029aa2a4c0c018cac903ee9e56bb21a93d08c0은 검증한 로컬 트리와 정확히 일치한다. 공개 author.html에서 최종 생성 작업 JSON을 복원하여 제목·참고2개·분류·AI검토·사용자확인0/5를 확인했다. 공개 의미 검색의1908 후보와 실제1022 상세의 ‘제작에 참고’ 링크를 확인했다. 현재 초안·1022·1908·최종 대조 지침을 포함한 수정 프롬프트24,895자를 생성했다. 실제 공개 화면을 leet-authoring-live-preview.png로 저장했다.

## 코드 검토와 수정

독립 리뷰에서 실패한 의미 검색 클라이언트가 재사용되는 문제와 false/0/빈 문자열 draft를 가진 작업이 기존 초안을 지우는 문제를 발견했다. 실제 worker 실패 및 잘못된 작업 가져오기 회귀 검사를 먼저 실패시킨 뒤 수정했다. 검토 표시 변경 후 복사 가능한 프롬프트가 오래된 내용을 담는 문제도 수정했다. 초기 저장 접근 실패 표시, 새 작업의 백업, 한글 바이트 용량을 고려한 작업 복원 한도, 선택지 번호의 중복 표시와 보완 응답 변경 후 프롬프트 무효화도 확인했다.

## 남는 판단 범위

사이트는 생성형 모델을 내장하지 않으며 복사한 프롬프트의 ChatGPT 실행은 사용자가 수행한다. AI의 pass는 독립 검증이 아니다. 복잡한 논리의 정답·난도·외부 문항과의 유사성은 사람이 원문과 계산·반례를 확인해야 한다. 제작 프롬프트와 독립 재검토 프롬프트는 이 검토를 돕고, 화면의 사용자 확인은 실제 확인한 항목만 기록한다.
