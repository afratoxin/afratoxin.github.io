# 원본 HWP 서식 보존 수정

이전 출력은 페이지 크기와 외부 표를 보존했지만 원본의 직접 문단 서식을 스타일 기본값으로 다시 만들었다. 정답·난도 표와 회색 논평 상자를 일반 문단으로 대체했고, 본문 표에는 7pt 정보 표 글꼴을 사용했으며 HFT를 바탕·돋움으로 바꿨다. 이 결과를 양식에 맞는 완성본이라고 판단한 것은 잘못이었다.

현재 구현은 실제 원본의 각 문단·표·상자를 복제하여 내용만 교체한다. 발문 번호와 본문 글자 서식을 구분하고, 조건 문단의 내어쓰기와 선택지 문단의 직접 서식을 유지한다. 숨은 메모에 선택지 스타일이 지정되어 있어 실제 바깥쪽 선택지 문단만 선택한다. 정답 정보 표, 논평 상자, 정오판단 캡슐, 상단 메모 서식은 원본 구조를 유지한다. 예시의 사실관계 표는 원본 표의 11pt 서식을 사용한다. 원본과 출력의 HEAD(글꼴·스타일 정의)는 동일하다. 별도 문서 처리용 매크로는 출력에서 제거한다.

원본 글꼴이 사라져 보였던 원인은 직접 PDF 저장 경로였고 한글의 전체 페이지 이미지 출력에서는 HFT가 정상 표시됐다. `PrintToImage`로 원본 글꼴과 전체 페이지를 출력하며, HWP/HWPX는 편집 가능한 형태로 저장한다. 이미지 기반 PDF는 이 PNG와 같은 모양의 미리보기이다. 글꼴 대체나 정답 표 해체는 기본 경로에서 수행하지 않는다.

## 확인

- 원본을 직접 출력한 전체 페이지와 최종 HWP에서 출력한 페이지를 비교했다. 외부 표·상단 서식·중앙 눈금·발문·조건 내어쓰기·11pt 표와 선택지·오른쪽 정답 정보 표·회색 논평 상자·정오판단 캡슐을 확인했다.
- 최종 실제 출력은 `지원금_원본서식_수정.hwp`이며 한글에서 다시 열어 문항·지문·표·풀이·선택지 해설을 대조했다. 한 페이지, 원본 파일 해시 불변, 글꼴 대체 0건을 확인했다.
- 전체 Python 50/50, HWP 관련 13/13 검사를 통과했다. 원본 표/상자가 사라지는 경우, 직접 문단 서식이 기본값으로 바뀌는 경우, 숨은 메모 글꼴이 선택지에 적용되는 경우를 먼저 실패시킨 후 수정했다.
- 공개 사이트의 검색·프롬프트·복사 UI는 변경하지 않았다. 수정 대상은 로컬 HWP 출력과 사용 설명이다.
