# HWP 문항 출력

## 출력 방식

ChatGPT 제작 프롬프트는 기본적으로 **문항만** 요청한다. 번호를 붙인 발문 → 지문·규칙·보기·표 → ①~⑤ 순서이며 정답·해설·분류·제작 기록을 붙이지 않는다. **문항과 해설**을 선택하면 뒤에 정답·핵심 풀이·선택지 판정을 덧붙인다. **구조화 JSON**은 기존 분류·검토 작업을 계속할 때 선택한다.

JSON 초안을 사이트에 가져오면 완성 문항을 별도 텍스트 칸에서 확인하고 복사하거나 TXT로 저장할 수 있다. 해설 포함 출력도 별도 제공한다. 출력은 필요한 필드만 조합하며, '정답' 같은 단어가 들어 있다는 이유로 문항 내용을 삭제하지 않는다. 자동 복사가 거부되면 해당 칸을 선택하여 수동으로 복사하게 한다.

## 로컬 한글 양식 채우기

`scripts/hwp_template.py`는 Windows에 설치된 한글의 자동화 기능을 사용한다. 브라우저 자체의 HWP 다운로드 기능은 아니다. 필요 패키지는 `pywin32`, `pypdf`이며, 한글 2022에서 HWP/HWPX/PDF 저장 및 다시 열기를 확인했다. HWP 원본은 사용자가 로컬 경로로 지정하며 공개 저장소에 넣지 않는다.

LEET Atlas 폴더에서 실행하는 예:

```powershell
python scripts/hwp_template.py --template 'C:/local/문항양식.hwp' --input 'C:/local/제작작업.json' --output 'C:/local/완성문항.hwp' --compatible-fonts
```

입력은 작업실에서 저장한 작업 JSON 또는 draft 객체이다. `publication` 객체를 추가하면 `blocks`(paragraph/heading/table), `intent`, `solution`, `optionReasons`, `optionTruth`(참/거짓 boolean 5개), `theme`, `memo`, `author` 등 인쇄용 내용을 지정할 수 있다. table 블록은 같은 열 수의 `rows`를 사용한다. HWP에는 이 인쇄용 구성을 사용하고 문항만 TXT는 draft의 완성 문항을 사용하므로 두 내용을 일치시켜야 한다.

지원 양식은 외부 표의 2행 0열에 문항, 2행 5열에 중앙 눈금, 2행 6열에 해설을 가진 '1페이지1문항' 구조이다. 원본의 페이지 설정·스타일·외부 표를 유지하고 문항과 해설 내용을 교체한다. 긴 내용은 사용자가 인쇄용으로 정리해야 하며 자동으로 글자 크기를 줄이지 않는다.

동일 이름의 HWP, HWPX, PDF, 문항만 TXT를 만든다. 관련 출력 파일이 하나라도 있으면 중단하며 의도적으로 다시 만들 때만 `--overwrite`를 지정한다. 원본 양식·입력과 겹치는 출력 경로는 허용하지 않는다. 원본 복사본으로 작업하고 마지막에 원본 해시가 그대로인지 확인한다. 한글의 덮어쓰기 확인창을 피하도록 별도 임시 출력 폴더에 새 파일로 저장하고 검증한 뒤 최종 경로로 복사한다. 검증 실패 시 기존 출력은 유지한다.

HFT 글꼴이 설치된 환경에서 PDF 글자가 사라질 경우 `--compatible-fonts`로 명조 계열은 바탕, 나머지는 돋움 TTF로 바꿀 수 있다. 오른쪽 정보 표는 설치된 한글 PDF에서 마지막 열이 잘려 두 개의 일반 문단으로 배치한다. 페이지 크기와 좌우 구성은 보존하지만 글꼴과 이 정보 배치는 원본과 다를 수 있다.

저장한 HWP를 다시 열어 실제 문항·해설의 텍스트를 대조하고, PDF에서도 지문·표·선택지·풀이·선택지 해설을 확인한다. 한글의 일반 텍스트 추출은 일부 기호를 문자 참조로 내보내므로 다시 연 HWP의 XML을 파싱하여 비교한다. PDF가 1페이지가 아니거나 본문이 누락되면 성공으로 처리하지 않는다. PDF 페이지의 겹침·여백·표 선은 별도 렌더링으로 눈으로 확인한다.
