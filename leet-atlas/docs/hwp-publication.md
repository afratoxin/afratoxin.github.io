# HWP 문항 출력

## 출력 방식

ChatGPT 제작 프롬프트는 기본적으로 **문항만** 요청한다. 번호를 붙인 발문 → 지문·규칙·보기·표 → ①~⑤ 순서이며 정답·해설·분류·제작 기록을 붙이지 않는다. **문항과 해설**을 선택하면 뒤에 정답·핵심 풀이·선택지 판정을 덧붙인다. **구조화 JSON**은 기존 분류·검토 작업을 계속할 때 선택한다.

JSON 초안을 사이트에 가져오면 완성 문항을 별도 텍스트 칸에서 확인하고 복사하거나 TXT로 저장할 수 있다. 해설 포함 출력도 별도 제공한다. 출력은 필요한 필드만 조합하며, '정답' 같은 단어가 들어 있다는 이유로 문항 내용을 삭제하지 않는다. 자동 복사가 거부되면 해당 칸을 선택하여 수동으로 복사하게 한다.

## 로컬 한글 양식 채우기

`scripts/hwp_template.py`는 Windows에 설치된 한글의 자동화 기능을 사용한다. 브라우저 자체의 HWP 다운로드 기능은 아니다. 필요 패키지는 `pywin32`, `pypdf`, `reportlab`이며, 한글 2022에서 HWP/HWPX 저장·다시 열기와 원본 글꼴의 페이지 출력을 확인했다. HWP 원본은 사용자가 로컬 경로로 지정하며 공개 저장소에 넣지 않는다.

LEET Atlas 폴더에서 실행하는 예:

```powershell
python scripts/hwp_template.py --template 'C:/local/문항양식.hwp' --input 'C:/local/제작작업.json' --output 'C:/local/완성문항.hwp'
```

입력은 작업실에서 저장한 작업 JSON 또는 draft 객체이다. `publication` 객체를 추가하면 `blocks`(paragraph/heading/table), `intent`, `solution`, `optionReasons`, `optionTruth`(참/거짓 boolean 5개), `theme`, `commentTitle`, `author` 등 인쇄용 내용을 지정할 수 있다. table 블록은 같은 열 수의 `rows`를 사용한다. HWP에는 이 인쇄용 구성을 사용하고 문항만 TXT는 draft의 완성 문항을 사용하므로 두 내용을 일치시켜야 한다.

지원 양식은 외부 표의 2행 0열에 문항, 2행 5열에 중앙 눈금, 2행 6열에 해설을 가진 '1페이지1문항' 구조이다. 원본의 실제 발문·본문·조건·표·선택지 문단을 복제하여 문단의 직접 서식과 글자 서식을 유지한다. 이름이 같은 스타일의 기본값만으로 다시 만들지 않는다. 숨은 메모에 선택지 스타일이 있어도 실제 본문의 선택지 문단을 사용한다. 본문 표는 원본의 11pt 표 서식을 쓰며, 데이터에 맞춰 행·열 수와 열 비율만 조정한다.

오른쪽의 정답·난도·내용 영역·문항 유형 표, 회색 논평 상자 한 개, 정오판단 캡슐과 해설 문단을 원본에서 복제한다. 전체 페이지 설정·외부 표·글꼴 정의·중앙 눈금·고정 메모 서식은 유지한다. 문항별 내용 길이에 따라 내부 표 높이는 늘어난다. 긴 내용은 인쇄용으로 정리해야 하며 글자 크기를 자동으로 줄이지 않는다. 원본의 별도 문서 처리 매크로는 완성 문항에 포함하지 않는다.

동일 이름의 HWP, HWPX, PNG, PDF, 문항만 TXT를 만든다. 관련 출력 파일이 하나라도 있으면 중단하며 의도적으로 다시 만들 때만 `--overwrite`를 지정한다. 원본 양식·입력과 겹치는 출력 경로는 허용하지 않는다. 원본 복사본으로 작업하고 마지막에 원본 해시가 그대로인지 확인한다. 한글의 덮어쓰기 확인창을 피하도록 별도 임시 출력 폴더에 새 파일로 저장하고 검증한 뒤 최종 경로로 복사한다. 검증 실패 시 기존 출력은 유지한다.

기본 출력은 원본 HFT 글꼴을 그대로 유지한다. 한글의 `PrintToImage`로 페이지 전체를 PNG로 출력하고 이 이미지를 미리보기 PDF에 넣는다. `CreatePageImage`는 이 중첩 표 양식의 내부만 잘라 출력했고, 한글의 직접 PDF 저장은 HFT 글자를 누락시켰다. 미리보기 변환 문제를 해결하기 위해 HWP 글꼴이나 정답 표를 변경하지 않는다. PDF는 이미지 미리보기이며 편집은 HWP/HWPX에서 한다. 명시적으로 글꼴 대체를 원하는 경우에만 `--compatible-fonts`를 사용할 수 있다.

저장한 HWP를 다시 열어 실제 문항·해설의 텍스트를 대조한다. 한글의 일반 텍스트 추출은 일부 기호를 문자 참조로 내보내므로 다시 연 HWP의 XML을 파싱하여 비교한다. 한글의 실제 페이지 수와 PDF 페이지 수가 각각 1인지 검사한다. 최종 PNG에서 글꼴·표·발문·선택지·논평 상자·정답 표·여백·겹침을 원본 출력과 대조하여 확인한다.
