# 2027 추리논증 검수판

사용자가 제공한 20회분 PDF 중 2027학년도 40문항만 2701~2740으로 우선 구축한다. 이 판의 원문·분류·해설을 사용자가 검수한 뒤에 다른 연도로 확장한다.

정적 HTML/JS와 JSON을 afratoxin/afratoxin.github.io의 독립된 leet-atlas 경로에 추가한다. 기존 블로그와 다른 퀴즈의 파일은 수정하지 않는다. 별도 서버와 계정은 필요하지 않다.

- 원본: 각 문항의 PDF 영역을 손실 없는 WebP 이미지로 보존한다. 추출 텍스트도 제공하며 위치 기반 공백·개행 복원과 문자 추출의 한계를 명시한다. 원문에 없는 내용을 본문에 채워 넣지 않는다.
- 정답: 원본의 회색 강조 표시를 독립 풀이와 대조한다. 외부 공식정답표 대조 여부를 분리한다. 논리상 충돌이 있는 문항은 원본을 유지하며 검토 표시한다.
- 분류: 연도/번호, 대범주, 세부소재, 문항유형, 풀이논리를 독립 축으로 둔다. 번호대에 따른 자동 분류는 하지 않는다. 태그마다 정의와 해당 문항에 붙인 이유를 표시한다.
- 화면: 위쪽 태그, 왼쪽 원문, 오른쪽 해설. 목록에는 문항번호·소재명·원본 썸네일을 표시한다. 검색, 축별 교차 필터, 고유 주소, 글자크기, 원본 확대와 로컬 검수 메모를 제공한다.
- 검수: 40개 ID/이미지/텍스트 완결성, 5개 선지 해설, 태그 참조, 추출 전후 문자 집합, 원본 표시 답안, 정답 충돌 표시를 확인한다.
