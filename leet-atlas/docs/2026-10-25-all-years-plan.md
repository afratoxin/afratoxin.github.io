# 전체 회차 소재·태그 적용 계획

사용자가 이전 대화에서 승인한 범위: 예비시험을 포함한 20회분 전체 문항을 읽고, 세부소재를 분야 아래 1~2단계 중간 범주로 통합해 GitHub의 기존 아카이브에 적용한다.

- [ ] 원본 PDF의 회차별 문항 수·번호·페이지를 검증하고 원문을 추출한다.
- [ ] 기존 분야를 유지하며 모든 문항에 중간 소재·문항 유형·풀이 논리와 구체적인 분류 이유를 부여한다. 단순 키워드 일괄 매핑에 의존하지 않는다.
- [ ] 기존 2027 수정 원문·해설·정답과 기존 북마크를 보존한다. 새 회차에 검증하지 않은 정답·해설을 생성하지 않는다.
- [ ] 전체 회차 데이터를 기존 UI에 연결하고 예비시험과 정규시험을 구별한다. 7색 북마크·10개씩 페이지 보기·태그 사전을 유지한다.
- [ ] 전체 755문항의 누락·중복·태그 참조·분류 이유·원본 출처와 UI 동작을 검증한다.
- [ ] 최신 GitHub 커밋을 기준으로 변경 파일만 원자적으로 반영하고 Pages 배포 결과를 확인한다.

데이터 인터페이스: `data/archive.json`은 기존 `data/2027.json`의 questions/taxonomy 형태를 따른다. `examKey`, `examLabel`로 예비시험을 구별하고, 기존 ID 2701~2740은 유지한다. UI는 archive.json을 읽는다. 새 분류 결과는 원문 ID별로 결합한다. 상세 소재의 구 ID는 alias로 남겨 기존 링크를 중간 범주로 연결한다.

검증 초점: 예비시험 ID의 딥링크, 동일 연도 2009 예비/본 시험 구별, 오래된 북마크 보존, 새 회차의 정답 확인 전 표시, 모든 페이지와 태그의 755문항 합계, 원본 수식과 표의 가독성.
