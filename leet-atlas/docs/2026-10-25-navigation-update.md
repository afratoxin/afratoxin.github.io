# 검수판 탐색과 분류 개선

사용자가 검수하면서 요청한 UI 개선을 먼저 반영한다. 전체 연도 문항 태깅은 이 UI를 확인받은 뒤 별도 단계로 진행한다.

- 기존 북마크와 메모를 유지하고 빨강·주황·노랑·초록·파랑·남색·보라 북마크를 제공한다. 한 문항에 여러 색을 붙일 수 있다. 기존 단색 북마크는 빨강으로 이관한다.
- 상단에 북마크 전용 화면과 7색 필터를 둔다.
- 기본 목록은 한 페이지에 10문항, 넓은 화면에서는 한 줄에 2문항이다. 연속 스크롤로 전환할 수 있다. 필터를 바꾸면 첫 페이지로 돌아간다.
- 대범주 아래에 넓은 세부 분야(field)를 추가한다. 기존 세부 소재(subject)·유형·풀이 논리는 유지한다. 현재 문항이 없는 분류는 0건으로 표시한다.
- 모든 태그를 모은 디렉터리와 각 태그의 정의·배정 이유·해당 문항을 보여 주는 묶음 화면을 제공한다.
- 사용자가 올린 수정 PDF와 이미지에 따라 2708을 갱신한다. 수정 전 원문과 현재 원문을 혼동하지 않도록 이력을 남긴다.

작업 파일 소유: core와 검증·통합은 root, app/index/styles는 UI 담당, 분야 카탈로그와 빌더는 분류 담당, 2708의 원자료와 분석은 문항 담당. 서로 다른 파일에서 병렬 작업한다.
