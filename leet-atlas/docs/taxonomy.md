# 분류 기준과 태그

문항 번호대가 아니라 실제 내용과 풀이에 따라 분류한다. 한 문항에 복수 태그를 허용하며 선택한 태그를 모두 갖는 문항만 표시한다.

풀이 논리는 [SDSS 100개의 코드](https://sdss.kr/code/100.html)를 참고한 자체 분류다. 참고 번호는 원코드이고, 프로젝트의 분류를 SDSS 공식 문항 분류로 표시하지 않는다.
