# 강화·약화 소분류와 문항별 태그

기존 강화·약화 145문항과 발문·보기에서 관련 표현이 확인된 추가 후보 44문항, 총 **189문항**의 원문과 자체 해설을 대조했다. **168문항에 13개 하위 태그를 총 356건** 부여했다. 단순 규칙 적용·내용 추론 등 21문항은 이번 소분류에서 제외하고 사유를 남겼다. 전체 755문항의 재풀이·공식 정답 대조를 뜻하지 않는다.

분류 축은 **풀이 논리(logic)**이며 상위 태그는 기존 **강화·약화(logic-strengthen)**다. 문항 유형(type)과 섞지 않는다. 한 문항에 판단상 혼동과 증거 작용 태그를 함께 붙일 수 있다. 같은 문항에 여러 선지가 있어 여러 태그가 붙으므로 아래 건수는 중복 집계다.

### 증거의 작용 방식

| 태그 | 문항 수 | 배정 기준 |
|---|---:|---|
| 근거의 신뢰성 변화 | 12 | 관찰·증언·자료선별·측정·대표성의 신뢰도를 높이거나 낮추어 논증을 평가한다. |
| 근거–결론 연결 변화 | 51 | 숨은 전제·유추·판정 기준 등 근거에서 결론으로 가는 연결을 보완하거나 끊는다. |
| 예측·반례 대조 | 72 | 가설·원칙에서 예상되는 결과와 실제 관찰·사례를 대조하여 지지나 반박을 판단한다. |
| 대안 설명 평가 | 27 | 관찰을 설명하는 다른 원인·경로·선택 효과·해석을 제시하거나 제거하여 기존 설명을 평가한다. |
| 수단–목적 평가 | 31 | 정책·행위가 목적을 달성하는지, 역효과를 내는지, 대체 수단이 있는지 평가한다. |

## 무관·중립·정보 부족의 경계

| 구분 | 확인할 내용 |
|---|---|
| 논점 무관 | 평가 대상의 주장·논거와 연결되는 정보인가? |
| 관련되지만 중립 | 관련은 있지만 핵심 조건이 그대로이거나, 명시한 비교에서 추가 판별력이 없는가? |
| 정보 부족·방향 미정 | 빠진 비교값·조건에 따라 강화와 약화 판단이 달라지는가? |

두 가설이 같은 관찰을 수용한다고 해서 그 관찰이 각각을 강화하지 않는 것은 아니다. 상대 비교의 판별력이 없는 경우에는 그 비교 대상을 근거에 명시한다. 예상과 양립하는 사실을 일률적으로 중립으로 분류하지 않는다. 한쪽의 강화·약화만으로 다른 쪽의 반대 효과를 도출하지 않는다.

## 화면에서 찾기

문항 목록에서 **풀이 논리 → 강화·약화**를 펼치면 두 묶음의 하위 태그를 고를 수 있다. 하위 태그를 선택한 링크를 열면 상위 항목도 자동으로 펼쳐진다. 태그 사전에도 두 묶음을 표시하며, 태그 설명과 문항별 분류 이유에서 실제 배정 근거를 확인할 수 있다. 연도끼리 OR, 나머지 태그끼리 AND라는 기존 조합 규칙을 사용한다.

## 자료와 재현

- 정의·배정 경계·문항별 검토 결과·선지별 근거: `data/logic-refinements.json`
- 실제 사이트의 문항별 태그·이름·사유: `data/archive.json`
- `unit`은 보기/선지, `target`은 평가 대상, `effect`는 그 증거의 실제 효과다. 선지 전체의 참·거짓 판정과 구별한다.
- `evidenceField`와 `evidenceText`는 원문의 정확한 근거 위치·발췌다. 공백을 제외한 연속 원문 포함 여부를 검증한다.
- 기존 관련성·중립 및 강화·약화 태그는 이전 링크 호환을 위해 보존한다. 새 세분류의 제외는 기존 태그 삭제를 뜻하지 않는다.
- `data/2027.json`은 수정본 보존 자료이므로 이번 작업에서 변경하지 않는다. 2027학년도 새 태그도 실제 사이트가 사용하는 `archive.json`에 반영된다.

```sh
python scripts/augment_taxonomy.py --archive data/archive.json --refinements data/logic-refinements.json --manifest data/archive-manifest.json
python -m unittest discover -s scripts -p "test_*refinements.py"
node --test scripts/sidebar.test.mjs scripts/tag-groups.test.mjs
```
