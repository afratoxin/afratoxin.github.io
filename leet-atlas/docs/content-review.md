# 2027학년도 내용 검토 반영

문항의 원문·정답·이미지·보기 판정·선지 해설은 유지하고, 요약의 과도한 단정과 태그 정의에 맞지 않는 대응을 수정했다. 원래 세부 논리 명칭은 `analysisLogicOriginal`에 남으며 관련 근거는 공통 태그 아래 합쳐진다.

- **2714:** 요약의 “㉠의 부탁은 B만 인정”을 “A는 인정하지 않고 B는 인정”으로 한정했다. C의 판단까지 배제하지 않는다. 성립 요건 대조는 `개념·기준 적용`으로 분류했다.
- **2724:** 표본에서 모집단으로 확대하는 `일반화·표본` 대신, 보편 원칙 P를 다른 분석가에게 적용하는 `보편 원칙 적용`을 자체 정의했다. 소재는 법률·인문, 학문은 과학철학·증거 추론으로 정리했다.
- **2727:** 인물 단서의 유사성에 따른 예측을 유비논증인 `유추`로 분류하지 않고 `경쟁가설 판별`에 합쳤다.
- **2716:** 비례 관계의 두 항을 바꿔 읽는 오류는 `비율·절대량` 대신 `표현·범위 해석`으로 분류했다.
- **2713·2726:** 효용·우월성의 판정 기준 적용을 인과분석용 `차이 비교`에서 `개념·기준 적용`으로 옮겼다. 2726의 `대소·성분별 비교`는 유지했다.
- **2718:** 작품이 명제를 포함한다는 표현만으로 집합 연산을 사용했다고 보지 않고 `개념·기준 적용`과 `표현·범위 해석`을 사용했다.
- **2703·2706·2711:** 각각 연산 순서를 `수식 계산`, 법적 구제의 예외 요건을 `원칙·예외 적용`, 두 필터의 순서 교환을 `집합·포함관계`로 정리했다. 비인과적 비교인 2710·2715·2728도 실제 기준 적용·대소 비교에 맞췄다.
- **분야·학문 근거:** 2727·2730의 `사회` 이유를 추가하고 `과학` 잔존 이유를 제거했다. 2723의 `인문` 이유를 보완했다. 물리학 공통 설명에서 상대론을 빼고 2736의 원자 에너지 준위·스펙트럼, 2738의 핵합성, 2740의 운동량·충격량을 문항별 이유로 적었다. 2732·2733의 대응·순서 퍼즐은 학문이 아닌 세부 주제로 내렸다.

논리 태그는 프로젝트의 자체 응용·자체 정의다. SDSS 원코드 번호는 참고 연결이며 이 프로젝트의 태그나 문항별 분류를 SDSS 공식 정의로 표시하지 않는다.

보류한 것은 `차이 비교`를 모든 일반 비교로 넓히는 제안이다. 기존 인과 비교 정의를 유지하면서 비인과적 적용을 다른 태그로 옮겼다. 공식 외부 정답표 대조의 미완료 상태도 그대로 유지한다.

`python scripts/build_data.py`와 `python scripts/validate_data.py`가 통과했다. 40문항, 선지 해설 200개, 태그 192개, 원본·썸네일 이미지 80개를 확인했다. 원문·정답·이미지 경로·보기 판정·선지 해설·풀이 단계의 변경 전후 해시가 같고, 현재 표시되는 모든 태그에 근거가 있음을 추가 확인했다.
