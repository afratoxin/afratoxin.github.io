# LEET Atlas — 추리논증 20회분 아카이브

예비시험과 2009~2027학년도 본시험의 **20회분 755문항**에 자체 작성 해설 초안과 **3,775개 선택지별 해설**을 제공합니다. 전체 문항의 소재·문항 유형·풀이 논리 및 분류 이유를 탐색할 수 있습니다.

문항 상세에서는 정답 선택지의 해설만 표시합니다. `<보기>` 문항은 ㄱ·ㄴ·ㄷ 등의 개별 판단과 정답 선택지의 설명을 함께 확인할 수 있습니다. 원본 선택지별 해설 데이터는 보존합니다.

- [문항 탐색](https://afratoxin.github.io/leet-atlas/#/questions)
- [7색 북마크 모아보기](https://afratoxin.github.io/leet-atlas/#/bookmarks)
- [태그 사전](https://afratoxin.github.io/leet-atlas/#/tags)
- [문항 제작 작업실](https://afratoxin.github.io/leet-atlas/author.html)

문항 제작 작업실에서는 만들고 싶은 요소를 자유롭게 입력해 기출을 찾고 최대5개를 참고 자료로 고를 수 있습니다. 선택한 기출의 요약·풀이·오답 함정으로 출제 논리를 살펴본 뒤, 원문·전체 선택지 해설·사용자의 변형 의도·분류 어휘·검토 지침을 담은 제작 프롬프트를 만듭니다. 프롬프트를 복사해 ChatGPT 웹에 직접 입력하거나 파일로 내려받을 수 있습니다. 현재 사이트 자체에는 생성 모델이나 유료 API가 없습니다.

ChatGPT가 돌려준 완성 JSON을 가져오면 새 문항의 지문·다섯 선택지·정답·해설과 분류 근거·AI 자체 검토가 함께 표시됩니다. 선택지 수·중복·정답 번호와 해설의 일관성을 검사하며 잘못된 입력은 기존 초안을 덮어쓰지 않습니다. ‘응답 보완·독립 재검토 프롬프트’는 원래 요청·기출 근거·받은 응답·형식 오류를 모아 새 채팅에서 문법과 전 선택지의 판정을 다시 검토하도록 요청합니다. AI의 pass는 독립적인 정답 검증이 아니므로 정답 유일성·조건 완결성·전 선택지 판정·기출 차별성·분류 근거를 사용자가 직접 확인할 수 있습니다. 초안 재반영은 수동 확인을 초기화합니다. 작업은 브라우저에 저장되며 작업 JSON 내보내기·복원, 문항 Markdown 내보내기를 지원합니다. ‘새 작업’은 현재 작업을 파일로 백업한 뒤 시작합니다. 개인 교정본은 생성 프롬프트에 자동 포함하지 않으며 공개 기출 자료를 사용합니다.

기본 목록은 10문항씩 표시하며 2열 보기와 연속 스크롤을 지원합니다. 문항 탐색·북마크·태그별 목록은 최신순이 기본이며, 오래된순/최신순/정확도 순을 선택할 수 있습니다. 정확도 순은 검색어와 문항 제목·본문의 일치도와 글자 유사도를 기준으로 가까운 문항을 먼저 표시하며 제목에 더 높은 가중치를 둡니다. 해설 확신도나 개인 정답률은 사용하지 않습니다. 검색어가 없거나 유사도가 같으면 최신순을 적용하고, 같은 회차의 동률 문항은 문항번호 순으로 표시합니다. 정렬을 바꾸면 첫 페이지로 이동하며 검색·태그·북마크 색은 유지합니다. 태그 조건은 자동으로 조합합니다. 서로 배타적인 연도 태그끼리는 OR로 묶고, 대범주·분야·소재·문항 유형·풀이 논리는 같은 축 안에서도 AND로 결합합니다. 이 다섯 축은 실제로 한 문항에 복수 태그가 배정되므로 축이 같다고 OR로 처리하지 않습니다. 예를 들어 `(2025 또는 2026) 그리고 논리 퍼즐`은 두 연도의 논리 퍼즐만 표시하며, 적용 중인 조건을 목록 위에서 확인할 수 있습니다. 이전 AND/OR 링크도 자동 조합 규칙으로 열립니다. 검색·북마크·검수 상태는 태그 조건과 함께 적용되고, 태그별 묶음 화면에서는 그 묶음 안에서 추가 태그를 적용합니다. 연도 묶음에서 다른 연도를 추가하면 두 회차를 합친 문항 탐색 화면으로 이동하며 다른 필터는 유지됩니다. 한 문항에 여러 북마크 색을 붙일 수 있고, 이전 북마크·메모·검수 기록은 같은 브라우저에 보존됩니다.

전체 **755문항의 원문 텍스트와 이미지가 공개 사이트에 포함**되어 있어 별도 파일을 불러오지 않아도 본문·썸네일·원본 확대를 바로 볼 수 있습니다. 2027학년도 40문항은 기존 수정 원문과 이미지를 그대로 유지하며, 나머지 715문항은 검수용 자료의 파싱 텍스트와 WEBP 이미지를 연결했습니다. 도표·수식·그림 선택지의 배치는 원문 이미지로 확인할 수 있습니다.

해설은 공식 해설이 아닌 자체 작성 초안이며 외부 공식 정답표 대조는 완료되지 않았습니다. 1034·2305·2435는 사용자 확인 후 원문을 재풀이하여 각각 ②·②·①로 해설을 수정하고 불일치 표시를 해제했습니다. 2305는 반복 위반의 2차·3차 기준에 각각 50%를 가산한 45일 계산을, 2435는 모든 조건을 만족하면서 남녀 동시 증가 혈액형이 0개인 반례를 제시합니다. 2708은 수정본의 ㄱ·ㄴ 참, ㄷ 거짓과 정답 ③을 보존합니다.

분류는 23개 분야 아래 중간 범주의 소재를 둡니다. 예: 경제학→게임이론, 철학→인식론·도덕·권리, 물리→운동법칙·천문·광학. 소재·문항 유형·풀이 논리는 별도 축입니다. 130개 이전 소재 링크도 현재 분류로 연결합니다.

## 검증

```sh
node --test scripts/*.test.mjs
python -m unittest discover -s scripts -p 'test_*.py'
python scripts/validate_archive.py
python scripts/validate_publication.py
python scripts/validate_data.py
node --check app.js
```

검증은 모든 문항의 데이터 완전성, 선지별 해설, 답안 충돌 표시, 2027 수정본 보존, 북마크·페이지·태그 동작을 확인합니다. DOM 어댑터 검증이며 실제 브라우저의 시각 검수를 대체하지 않습니다. 전체 문항의 독립 정답 검증이 완료되었다는 의미도 아닙니다.

`data/archive.json`은 현재 사이트 데이터, `data/2027.json`은 기존 수정본 보존 데이터입니다. 완성된 개인 원문 데이터에서 공개용 자체 해설만 추리려면 다음을 실행합니다.

```sh
python scripts/build_explanations_archive.py --input /path/to/full/archive.json --output /path/to/public/data/archive.json
```

풀이 논리 분류는 [SDSS 100개의 코드](https://sdss.kr/code/100.html)를 참고한 자체 분석입니다. 자세한 분류 기준은 `docs/taxonomy.md`, `docs/field-classification.md` 및 `docs/archive-classification.md`를 참고하십시오.

## 연관 태그와 내 본문

필터와 태그 사전은 태그를 의미가 가까운 묶음으로 나누어 보여줍니다. 분야는 법률·제도, 인문, 사회·경제·행동, 수학·논리·정보, 자연·생명과학으로 묶고 소재는 상위 분야로 묶습니다. 유형과 풀이 논리도 관련 기능끼리 묶으며, 연도는 연대별로 표시합니다. 태그 ID와 문항별 배정은 바꾸지 않습니다. 상위 분야나 연관 묶음 이름으로도 태그를 검색할 수 있습니다.

상단 **본문·이미지 불러오기**에서 LEET Atlas 본문 JSON 파일을 선택하면 해당 문항의 본문을 해설 옆에 표시하고 검색할 수 있습니다. 본문은 서버나 저장소로 보내지 않고 이 브라우저에만 보관합니다. 다음 회차 파일을 불러오면 기존 본문과 합칩니다. 각 문항의 **이 본문 지우기**로 삭제할 수 있으며 북마크·검수 메모는 유지합니다. 저장 공간이 부족하면 현재 탭에서만 표시한다는 안내가 나옵니다.

현재 공개 사이트에는 전체 원문이 기본 제공됩니다. 아래의 개인 파일 불러오기 기능과 빌더는 추가 검수 자료를 사용할 때 선택적으로 이용할 수 있습니다.

## 전체 회차 본문 연결

사이트를 열면 예비시험·2009~2027학년도 전체 회차의 본문이 바로 표시됩니다. 별도 가져오기 없이 본문 표시와 검색에 연결됩니다. **본문 755/755**가 표시되면 모든 문항의 본문을 볼 수 있습니다. 본문 수에 마우스를 올리면 회차별 연결 수를 확인할 수 있고 목록에도 **본문 있음**을 표시합니다. 재접속 시 복원되며 기존 메모·북마크·검수 상태를 유지합니다.

로컬 원본 데이터에서 본문 파일을 만들 때는 다음 빌더를 사용할 수 있습니다. 개인 검수용 파일을 생성하는 선택 기능이며 기본 공개 원문을 표시하는 데 필요하지 않습니다.

```sh
python scripts/build_local_text_pack.py --input /path/to/full/archive.json --registry data/archive.json --output /path/to/leet-text-all-years.json --corrections /path/to/verified-corrections.json
```

빌더는 회차·문항번호·원문 쪽수·중복·잘못된 문자·선택지 번호를 검사하고, 원본 대조로 확인한 보정만 정확히 일치하는 텍스트에 적용합니다. 그림 선택지와 도식의 배치는 원본 PDF와 함께 확인해야 합니다.

## 계층 필터와 세부 유형

왼쪽 필터는 **대범주·문항 유형·풀이 논리·연도** 네 토글로 시작합니다. 대범주 아래 분야, 분야 아래 소재를 펼쳐 선택합니다. 문항 유형은 토글 안에서 기본 9유형을 고르고, 논리 퍼즐과 실험 분석을 펼치면 세부 유형을 고를 수 있습니다. 연도끼리 OR, 나머지 선택 태그는 AND로 결합합니다.

논증 구조도는 실제 지지·결론 도식을 직접 해석하는 10문항입니다. 일반 논증 구조와 기존 태그도 유지합니다. 논리 퍼즐 83문항에는 거짓말 찾기·배열하기·술어논리·계산하기·대응/분류·경로/관계·조건 추론을 겹쳐 부여할 수 있습니다. 실험 분석 73문항은 사회과학31·자연과학38·방법론4로 나눴습니다. 사람/동물이라는 대상 자체보다 설명할 가설과 측정할 결과를 우선합니다. 예를 들어 임상 약효는 자연과학, 범죄 예방과 선택 행동의 효과는 사회과학, 일반 눈가림·자료선별 기준은 방법론입니다.

모든 추가 분류와 문항별 근거는 `data/type-refinements.json`에 있으며 다음 명령으로 재현합니다.

```sh
python scripts/augment_taxonomy.py --archive data/archive.json --refinements data/type-refinements.json --manifest data/archive-manifest.json
```

## 본문과 이미지 함께 불러오기

이전 텍스트 전용 파일에는 이미지가 없습니다. **본문·이미지 불러오기**에서 이미지가 포함된 전체 원문 파일을 한 번 선택하면 715문항의 텍스트·썸네일·원본 보기·확대가 함께 연결됩니다. 기존2027 원문40개를 합쳐 **본문755/755 · 이미지755/755**를 확인할 수 있습니다. 기존 텍스트 전용 파일도 계속 사용할 수 있습니다.

별도로 불러온 개인 자료는 이 브라우저의 IndexedDB에 보관하며 기존 메모·북마크 저장소는 보존합니다. 기본 원문은 `data/archive.json`과 `data/images/*.json`으로 제공되고 이미지는 회차별로 필요한 때 불러옵니다. 연결 자료와 검사 범위는 `data/source-connection-report.json`에서 확인할 수 있습니다.

```sh
python scripts/build_local_source_pack.py --text-pack /path/to/leet-text-all-years.json --registry data/archive.json --image-dir /path/to/original-question-crops --output /outside/the/repository/leet-sources-all-years.json
```


## 출제 구상으로 참고 문항 찾기

문항 제작 작업실의 **ChatGPT 출력 형식**은 **문항만**이 기본입니다. 번호를 붙인 발문, 지문·필요한 보기, ①~⑤ 선택지 순서의 일반 텍스트를 요청하며 정답·해설·출제 메모는 붙이지 않습니다. **문항과 해설**은 완성 문항 뒤에 간결한 정답·풀이·선택지 판정을 별도로 요청합니다. 두 형식의 응답은 ChatGPT에서 그대로 복사하여 사용합니다.

기존 분류·검토 기능은 **구조화 JSON** 모드에서 사용할 수 있습니다. JSON 응답을 선택 단계에서 가져오면 **문항만 복사 / 문항 TXT**와 **문항과 해설 복사 / TXT**로 사용할 수 있으며 이 출력에는 분류·검토 기록이 포함되지 않습니다. 검토 기록 전체는 별도 Markdown으로 보관할 수 있습니다. 출력 형식은 작업 JSON에 저장되며 이전 작업 파일은 문항만 모드로 열립니다.

설치된 한글에서 로컬 HWP 양식을 채우는 방법은 [HWP 문항 출력](docs/hwp-publication.md)에 있습니다. 실제 양식 파일은 로컬 입력으로만 사용하며 저장소에 포함하지 않습니다. 이 기능은 Windows의 한글 자동화로 실행하고, 사이트에서는 문항 복사·TXT 저장을 제공합니다.

문항 탐색은 **설명으로 추천받기**와 **단어로 검색하기**를 별도 입력으로 구분합니다. 추천에서는 만들고 싶은 문항의 소재·풀이 과정·논증 관계·선택지의 함정·문항 형식을 자유롭게 설명하고 **참고 문항 찾기**를 누릅니다(Ctrl/⌘+Enter도 가능). 새 문장을 미리 등록할 필요 없이 전체755문항과 의미를 비교합니다. 화면의 예시 버튼은 보통 검색과 같은 경로를 쓰는 입력 편의 기능입니다.

검색 자료는 모든 원문,3,775개 선택지 해설,보기 판단,풀이와 주의점에 더해 전체755문항의 일반적인 출제 특징·추론 과정·함정 설명을 포함합니다. 문항마다 원래 해설의 정확한 근거 인용을 연결했습니다. 소재의 우연한 단어뿐 아니라 다른 소재에서도 재사용할 수 있는 논증 관계를 찾는 데 활용합니다. **관련 부분**과 **분석의 근거 보기**를 열어 추천 이유를 직접 확인할 수 있습니다. 정답 선택지가 아닌 선택지의 관련 해설도 검색 카드에서 볼 수 있습니다.

추천은 관련성이 높은 후보 목록이며 직접 고른 태그·연도·북마크·검수 상태만 필수 조건으로 유지합니다. 자연어로 언급한 분류·형식·제외 표현은 순위 보조 정보로 활용합니다. 두 방식의 입력은 각각 보관하며, 추천 문장을 고치는 동안 이전 검색 결과를 새 결과로 표시하지 않습니다.

**단어로 검색하기**는 공백으로 나눈 모든 단어가 문항번호·회차·제목·본문·분류·해설·검색 설명에 실제로 포함되는 문항을 찾습니다. 문항번호를 정확히 입력하는 검색도 유지합니다. 검수 상태는 입력 방식과 분리된 목록 필터에서 고릅니다.

문장 의미 비교는 브라우저에서 실행합니다. 첫 사용에는 다국어 검색 모델 약118MB와 실행 자료를 공개 배포처에서 내려받으며, 이후 브라우저 캐시를 재사용합니다. 별도 계정·API 키·AI 호출 요금은 없고 입력 문장을 외부 추론 서비스로 보내지 않습니다. 준비 중에도 관련 표현·분류 검색 결과를 먼저 보여주며, 기기나 네트워크 사정으로 준비하지 못하면 그 상태를 알립니다. 개인 교정본은 표현 검색에 반영하지만 미리 계산한 의미 자료는 공개 원문을 기준으로 합니다.

검색 자료는 `data/reference-search-manifest.json`에 원본 해시·모델 버전·계산 범위를 기록합니다. 원문이나 분류를 바꾸면 `scripts/build-search-index.mjs`로 다시 계산해야 합니다. 모델 파일과 생성용 패키지·캐시는 공개 저장소에 포함하지 않습니다.


의미 검색 자료를 다시 계산하는 예시(LEET Atlas 폴더에서 실행):

```powershell
npm.cmd install --prefix ../.search-work/semantic-runtime @huggingface/transformers@3.8.1
node scripts/build-search-index.mjs --runtime ../.search-work/semantic-runtime/node_modules/@huggingface/transformers/dist/transformers.node.mjs --evaluate
```

현재 검색 자료는755문항의19,362개 짧은 문서를384차원으로 계산한 것입니다. 모든 원문 조각은 겹치게 나누어 뒷부분도 포함하고 각 벡터에 실제 문단과 출처 이름을 연결합니다. 생성 후에는 `node --test scripts/*.test.mjs`로 원본 해시·프로필 근거·검색 자료의 대응을 확인합니다.

검수한 일반 검색 설명의 편집 원본은 `data/search-profiles.json`, 브라우저용 자료는 `search-profile-data.mjs`입니다. 원문이 바뀌면 기존 설명의 유효 표시를 무효화합니다. 해당 문항 설명과 근거를 다시 검수하고 원문 표지를 갱신한 뒤, `node scripts/compile-search-profiles.mjs`와 검색 자료 계산을 실행합니다. 이 자료는 검색 문장별 답안 목록이 아니며 실행 중 새 해설을 생성하지 않습니다. 원문 이미지의 빈칸 관찰은 원문 텍스트와 연결된 `search-visual-evidence.mjs`에 별도로 기록합니다.

참고 문항 추천의 **관련성순**은 문장 의미와 구조를 함께 반영합니다. 기존 **정확도 순**은 제목·본문의 검색어 유사도 기준으로 유지하며, 검색 전의 기본 목록은 최신순입니다.

## 연도별 출제 분석

상단 **연도별 분석**에서 예비시험부터 2027학년도까지 20회차의 출제 논리·발문·선지·소재를 비교합니다. 회차별 설명은 수록 문항을 검토한 자체 분석이며 대표 문항의 원문·해설로 연결됩니다. 대조 회차를 선택하면 문항 수가 다른 회차도 비율로 비교할 수 있습니다. 복수 태그의 비율 합은 100%를 넘을 수 있습니다.

**풀이 부담 추정** 그래프는 발문·지문 읽기량, 조건 표지, 기존 논리 종류, 선지 비교량을 전체 755문항의 공통 기준으로 결합한 1~5단계 지표입니다. 실제 정답률이나 검증된 난이도 등급이 아닙니다. **공개 정답률 대조**는 책형·문항 대응을 확인한 외부 표본 통계만 표시하고, 미확보 값을 추정값으로 채우지 않습니다. 정확한 수치와 상한만 알려진 범위는 구별하며, 각 자료의 출처와 표본 한계를 함께 표시합니다.

분석 내용·외부 출처는 `data/year-analysis.json`, 산식·집계·그래프는 `year-analysis.mjs`에 있습니다. 새 내용은 기존 문항 데이터와 개인 검수 기록을 변경하지 않습니다.

### 연도별 2차원 출제 지도

연도별 분석 상단의 평면은 가로축에 모형·수리 추론 또는 논리 퍼즐 문항 비율, 세로축에 논증 평가 또는 실험 분석 문항 비율을 사용합니다. 한 축 안의 중복은 한 번만 세고 두 축은 독립 집계합니다. 점 하나가 시행 회차 하나이며 점을 누르면 해당 연도 분석으로 이동합니다. 점선은 전체 755문항의 비율이고, 동일 좌표는 실제 값을 이동시키지 않고 동심원과 개별 연도 이름으로 표시합니다. 좌표 표와 분류 기준도 함께 제공합니다. 난이도 순위를 뜻하는 지도는 아닙니다.

## 강화·약화 소분류

풀이 논리의 **강화·약화** 아래에 판단상 혼동 8종과 증거의 작용 방식 5종을 추가했습니다. 189개 후보를 원문·기존 자체 해설과 대조하여 168문항에 356건의 하위 태그를 부여했고, 단순 규칙 적용·내용 추론 등 21문항은 제외 사유를 기록했습니다. 무관·중립·정보 부족, 주장 귀속·평가 방향·경쟁 관계를 구별합니다. 필터에서 강화·약화를 펼쳐 선택하거나 태그 사전의 두 소분류 묶음을 사용할 수 있습니다.

정의·건수·대표 선지와 재현 방법은 [강화·약화 소분류](docs/strengthen-classification.md), 모든 검토와 원문 근거는 `data/logic-refinements.json`에 있습니다. 기존 태그·정답·해설은 보존합니다.
