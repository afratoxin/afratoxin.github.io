# LEET Atlas — 2027 추리논증 검수판

제공받은 20회분 자료 중 **2027학년도 40문항(2701~2740)**만 먼저 구축한 검수판이다. 다른 연도는 사용자 검수 뒤에 확장한다.

https://afratoxin.github.io/leet-atlas/

- 원본 문항 이미지, PDF 문자층 추출본, 문항별 다섯 선택지 해설을 제공한다.
- 연도·대범주·세부 소재·문항 유형·풀이 논리를 별도로 분류한다. 태그의 설명과 문항별 부여 이유를 툴팁으로 제공한다.
- 태그 교차 필터, 검색, 문항 고유 주소, 원본 확대, 브라우저 내 검수 메모를 지원한다.
- 정답은 제공 PDF의 회색 강조를 독립 풀이와 대조했다. **외부 공식 정답표 대조는 미완료**다.
- **2708**은 문면상 ㄴ만 참이나 이에 대응하는 선택지가 없다. 원본의 ③ 강조를 그대로 보존하고 불일치로 표시한다.
- **2723**의 선택지 도식과 **2736**의 수식은 원본 이미지를 기준으로 확인한다. 추출 오류 복원은 변경 이력을 남겼다. 텍스트 추출이 모든 도식을 문자로 표현한다는 주장은 하지 않는다.

## 검증

```sh
node --test scripts/core.test.mjs scripts/app.test.mjs
python scripts/validate_data.py
node --check app.js
```

`app.test.mjs`는 실제 앱의 생성 HTML·이동·필터를 최소 DOM 어댑터로 검사한다. 브라우저의 레이아웃이나 시각 검증을 대체하지 않는다. 이 작업 환경에는 브라우저 검수 도구가 없어 실제 브라우저 시각 검증은 수행하지 못했다.

## 데이터 재생성

```sh
python scripts/build_data.py
```

제공 PDF에서 추출을 재현하려면 PyMuPDF·Pillow·Poppler가 필요하다. 검수된 데이터와 이미지를 덮어쓰지 않도록 새 출력 폴더를 사용한다.

```sh
python scripts/extract_pdf.py data/2027-original.pdf /tmp/leet-atlas-extraction --start-page 1
```

PDF의 원래 회색 강조는 보존한다. 본문 문장이나 원본 답안 표시를 임의로 교정하지 않는다. 위치 기반 추출 텍스트와 원래 문자층을 모두 보관한다.

## 출처와 분류

원문: 사용자가 제공한 `★ 추리논증 본고사 20회분(예비-27)(형광펜O)_260808수정.pdf`, 337~356쪽. `data/source-manifest.json`에 원본 파일 해시를, `data/extracted-2027.json`에 문항 영역 좌표를 기록했다.

풀이 논리 분류는 [SDSS 100개의 코드](https://sdss.kr/code/100.html)의 확인 가능한 코드명·별칭 및 일부 하위 검색자료를 참고한 자체 분석이다. SDSS의 공식 추리논증 분류나 공식 해설이 아니다. 상세 확인 범위는 `data/logic-research.json`에 기록했다.
