플레이 규칙과 원작 안내
  1. 문제판에서 안에 든 숫자의 합이 타깃 넘버와 같은 직사각형의 개수를 입력합니다. 정사각형과 숫자가 하나도 없는 네모도 조건이 맞으면 포함합니다. 빈칸은 0입니다. 분수는 표시된 값 그대로 더하고, 음수는 합에서 뺍니다.
  2. 테두리는 격자선을 따라야 합니다. 판 밖이나 짙은 구멍을 한 칸이라도 포함하면 네모가 될 수 없습니다. 구멍을 둘러싼 큰 네모도 제외합니다. 크기나 위치가 다르면 서로 다른 네모입니다.
  3. 방송식 도전은 문제당 5분. 버저를 누르면 남은 문제 시간과 무관하게 10초 안에 한 번 답합니다. 오답과 답변 시간 초과는 정답을 공개하지 않으며, 10초 뒤 같은 문제에 다시 답할 수 있습니다. 대기 중에도 문제의 5분 제한 시간은 흐릅니다. 풀이 시간은 문제 공개부터 계산하며 오답 대기를 포함합니다. 문제의 제한 시간이 끝나거나 포기하면 정답을 공개합니다. 정답 2회면 승리합니다.
  4. 자유 연습은 시간 제한 없이 답하며, 오답 후 10초 대기하면 같은 문제에 재도전합니다. 수동 카운터는 개수만 기록합니다.
