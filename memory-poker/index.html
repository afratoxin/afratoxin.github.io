족보 및 순위 기준

스트레이트 플러시 → 포카드 → 풀하우스 → 플러시 → 스트레이트 → 트리플 → 투페어 → 원페어 → 하이카드. A는 가장 높지만 A·2·3·4·5에서는 1로 사용합니다. 같은 족보는 구성 숫자와 키커로 비교하고, 무늬는 우열을 가리지 않습니다.

16장 중 2장을 고르는 120가지 선택을 모두 비교합니다. 나보다 강한 선택 수 + 1이 내 순위이며 같은 패는 공동 순위입니다. 실제 접속 상대와 대결하는 방식이 아닌 전체 선택 대비 순위 연습입니다. 공유 카드는 암기 시간이 끝난 뒤 공개됩니다. 문제마다 최강 족보가 달라집니다. 최강 족보는 투페어·트리플을 중심으로 다양하게 출제합니다. 같은 숫자 3장 이상도 허용하며, 매번 숫자 종류나 족보 순서를 일률적으로 맞추지 않습니다. 비공식 1인 연습 버전입니다.
